`@goopui/react` is now published to npm. Gooey shadcn/ui components for React 18/19 on Radix UI, versioned together with `@goopui/core`, `@goopui/vue` and `@goopui/nuxt`. Every component file is a client component (`'use client'`), so they render from Next.js App Router Server Components. Setup is one line in your Tailwind entry CSS: `@import "@goopui/react/goop.css";`.
