goopUI: the puddle

The mark is one goopy Slime-green puddle: a soft, slightly lumpy, round-ish blob, like a drop that just landed. It is not drawn by hand. It is the goop engine's own resting pose (core's SVG goo filter on a 52x38 round host with two lumps tucked into its underside), traced to Beziers. On the web the logo is live: apps/soon's GoopLogo.vue attaches the same engine with the same numbers, so the static SVG and the live goo are the same shape, and the blob wobbles toward the cursor, splashes droplets on fast passes and squishes on click. Reduced motion keeps this static mark. Wordmark: DynaPuff, ink = currentColor.
