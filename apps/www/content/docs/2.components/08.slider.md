## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports `GoopSlider` and adds `goop.css`. See [Installation](/docs/getting-started/installation) for the module options.

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopSlider` from `@goopui/react`.
::

## Usage

::fw
#vue
`GoopSlider` wraps the same [reka-ui Slider](https://reka-ui.com/docs/components/slider) as [shadcn-vue's Slider](https://www.shadcn-vue.com/docs/components/slider). The API is the same: `v-model` is an array with one number per thumb, and `min`, `max`, `step`, `orientation`, `dir`, `inverted`, `disabled`, `name`, and `minStepsBetweenThumbs` pass through to reka-ui.

#react
`GoopSlider` wraps the same [Radix Slider](https://www.radix-ui.com/primitives/docs/components/slider) as [shadcn/ui's Slider](https://ui.shadcn.com/docs/components/slider). The API is the same: `value` and `defaultValue` are arrays with one number per thumb, and `min`, `max`, `step`, `orientation`, `dir`, `inverted`, `disabled`, `name`, and `minStepsBetweenThumbs` pass through to Radix. Like shadcn/ui's, a slider with no `value` or `defaultValue` renders two thumbs, a range from `min` to `max`.
::

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports this. In plain Vue, import it:
import { GoopSlider } from '@goopui/vue'

const volume = ref([50])
</script>

<template>
  <GoopSlider v-model="volume" :max="100" :step="1" />
</template>
```

It emits `update:modelValue` while you drag, and `valueCommit` when you let go.

#react
```tsx
import { GoopSlider } from '@goopui/react'
import { useState } from 'react'

export function Volume() {
  const [volume, setVolume] = useState([50])
  return <GoopSlider value={volume} onValueChange={setVolume} max={100} step={1} />
}
```

It calls `onValueChange` while you drag, and `onValueCommit` when you let go.
::

## Behavior

::fw
#vue
- **Jelly.** The thumb follows your pointer on a spring. It lags, overshoots, and wobbles to rest (`jelly`).
- **Slosh.** The surface of the fill piles up toward the front when you move fast, then sloshes back and waves (`slosh`).
- **Stretch.** The thumb stretches along the track with speed (`stretch`).
- **Splat.** Click the track and the thumb jumps there, landing with a small splat (`splat`).
- **Layout** never changes. The goo is drawn in one `aria-hidden` layer on the slider root. The real range and thumbs stay in place and go see-through, so reka-ui keeps drag, keyboard, focus, and ARIA exactly as they were.
- The thumb keeps its hover and focus ring.

#react

## Effects and presets

Each effect is a prop. `false` turns it off, `true` uses the preset's strength, and a number from 0 to 2 scales it. `preset` picks `subtle`, `playful` (default), or `wild` for the whole slider. The first slider below has no jelly or stretch, then come `wild` and `subtle`:

::preview{:controls="false"}
:demo-slider{set="effects"}
::

::fw
#vue
```vue
<GoopSlider :default-value="[40]" :jelly="false" :stretch="false" />
<GoopSlider :default-value="[60]" preset="wild" />
<GoopSlider :default-value="[60]" preset="subtle" />
```

#react
```tsx
<GoopSlider defaultValue={[40]} jelly={false} stretch={false} />
<GoopSlider defaultValue={[60]} preset="wild" />
<GoopSlider defaultValue={[60]} preset="subtle" />
```

## Color

The goo is painted in `--primary`. To change it, set `--goop-slider-color` on the slider or any ancestor:

::fw
#vue
```vue
<GoopSlider :default-value="[50]" class="[--goop-slider-color:var(--destructive)]" />
```

The track keeps shadcn's `bg-muted`. Style it with `class` as you would in shadcn.

#react
```tsx
<GoopSlider defaultValue={[50]} className="[--goop-slider-color:var(--destructive)]" />
```

The track keeps shadcn's `bg-muted`. Style it with `className` as you would in shadcn.

## Driving it from code

::fw
#vue
`GoopSlider` exposes the core handle and its root element. `handle.measure()` re-measures the thumbs after you change the layout by hand. `handle` is `null` before mount and when `goo` is off.

```vue
<script setup lang="ts">
const slider = useTemplateRef('slider')
</script>

<template>
  <GoopSlider ref="slider" :default-value="[50]" />
  <button @click="slider?.handle?.measure()">Re-measure</button>
</template>
```

#react
`goopRef` receives the core handle, and `ref` is the root `<span>`, as in shadcn/ui. `measure()` re-measures the thumbs after you change the layout by hand. The handle is `null` before mount and when `goo` is off.

```tsx
import { GoopSlider, type SliderHandle } from '@goopui/react'
import { useRef } from 'react'

export function Measured() {
  const slider = useRef<SliderHandle>(null)
  return (
    <>
      <GoopSlider goopRef={slider} defaultValue={[50]} />
      <button onClick={() => slider.current?.measure()}>Re-measure</button>
    </>
  )
}
```

## Accessibility

::fw
#vue
It's a real reka-ui slider: each thumb has `role="slider"` and the ARIA values, and arrow keys, Home, End, and Page Up/Down work as in shadcn. The goo layer is `aria-hidden` and can't be clicked. An `aria-label` you pass lands on the slider root, as in shadcn. Under reduced motion the goo keeps its shape and the effects turn off: no jelly, slosh, stretch, or splat. The thumb just follows the value. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
It's a real Radix slider: each thumb has `role="slider"` and the ARIA values, and arrow keys, Home, End, and Page Up/Down work as in shadcn. The goo layer is `aria-hidden` and can't be clicked. An `aria-label` you pass lands on the slider root, as in shadcn. Under reduced motion the goo keeps its shape and the effects turn off: no jelly, slosh, stretch, or splat. The thumb just follows the value. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
::
