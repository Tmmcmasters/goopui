#react
`GoopSidebar` is shadcn/ui's Sidebar with the same parts and API: `useSidebar()`, the `sidebar_state` cookie, the Ctrl/Cmd+B shortcut, `side`, `variant`, `collapsible`, `defaultOpen` / `open` / `onOpenChange` on the provider, and a mobile sidebar below 768px. Swap the imports and you're done.

## Installation

::fw{when="vue"}

### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopSidebar*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and shadcn's sidebar tokens (`--sidebar`, `--sidebar-accent`, `--sidebar-border`, ...).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). It needs Tailwind CSS v4 and shadcn's sidebar tokens (`--sidebar`, `--sidebar-accent`, `--sidebar-border`, ...).
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them from '@goopui/vue'.
</script>

<template>
  <GoopSidebarProvider>
    <GoopSidebar collapsible="icon">
      <GoopSidebarHeader>...</GoopSidebarHeader>
      <GoopSidebarContent>
        <GoopSidebarGroup>
          <GoopSidebarGroupLabel>Platform</GoopSidebarGroupLabel>
          <GoopSidebarMenu>
            <GoopSidebarMenuItem>
              <GoopSidebarMenuButton is-active tooltip="Dashboard">
                <House /><span>Dashboard</span>
              </GoopSidebarMenuButton>
            </GoopSidebarMenuItem>
            <GoopCollapsible as-child class="group/collapsible">
              <GoopSidebarMenuItem>
                <GoopCollapsibleTrigger as-child>
                  <GoopSidebarMenuButton tooltip="Documentation">
                    <BookOpen /><span>Documentation</span>
                  </GoopSidebarMenuButton>
                </GoopCollapsibleTrigger>
                <GoopCollapsibleContent>
                  <GoopSidebarMenuSub>
                    <GoopSidebarMenuSubItem>
                      <GoopSidebarMenuSubButton href="#">Introduction</GoopSidebarMenuSubButton>
                    </GoopSidebarMenuSubItem>
                  </GoopSidebarMenuSub>
                </GoopCollapsibleContent>
              </GoopSidebarMenuItem>
            </GoopCollapsible>
          </GoopSidebarMenu>
        </GoopSidebarGroup>
      </GoopSidebarContent>
      <GoopSidebarFooter>...</GoopSidebarFooter>
      <GoopSidebarRail />
    </GoopSidebar>
    <GoopSidebarInset>
      <header><GoopSidebarTrigger /></header>
      <!-- your page -->
    </GoopSidebarInset>
  </GoopSidebarProvider>
</template>
```

#react
```tsx
import {
  GoopCollapsible,
  GoopCollapsibleContent,
  GoopCollapsibleTrigger,
  GoopSidebar,
  GoopSidebarContent,
  GoopSidebarGroup,
  GoopSidebarGroupLabel,
  GoopSidebarInset,
  GoopSidebarMenu,
  GoopSidebarMenuButton,
  GoopSidebarMenuItem,
  GoopSidebarMenuSub,
  GoopSidebarMenuSubButton,
  GoopSidebarMenuSubItem,
  GoopSidebarProvider,
  GoopSidebarRail,
  GoopSidebarTrigger,
} from '@goopui/react'
import { BookOpen, House } from 'lucide-react'

export function AppShell({ children }: { children: React.ReactNode }) {
  return (
    <GoopSidebarProvider>
      <GoopSidebar collapsible="icon">
        <GoopSidebarContent>
          <GoopSidebarGroup>
            <GoopSidebarGroupLabel>Platform</GoopSidebarGroupLabel>
            <GoopSidebarMenu>
              <GoopSidebarMenuItem>
                <GoopSidebarMenuButton isActive tooltip="Dashboard">
                  <House /><span>Dashboard</span>
                </GoopSidebarMenuButton>
              </GoopSidebarMenuItem>
              <GoopCollapsible asChild className="group/collapsible">
                <GoopSidebarMenuItem>
                  <GoopCollapsibleTrigger asChild>
                    <GoopSidebarMenuButton tooltip="Documentation">
                      <BookOpen /><span>Documentation</span>
                    </GoopSidebarMenuButton>
                  </GoopCollapsibleTrigger>
                  <GoopCollapsibleContent>
                    <GoopSidebarMenuSub>
                      <GoopSidebarMenuSubItem>
                        <GoopSidebarMenuSubButton href="#">Introduction</GoopSidebarMenuSubButton>
                      </GoopSidebarMenuSubItem>
                    </GoopSidebarMenuSub>
                  </GoopCollapsibleContent>
                </GoopSidebarMenuItem>
              </GoopCollapsible>
            </GoopSidebarMenu>
          </GoopSidebarGroup>
        </GoopSidebarContent>
        <GoopSidebarRail />
      </GoopSidebar>
      <GoopSidebarInset>
        <header><GoopSidebarTrigger /></header>
        {children}
      </GoopSidebarInset>
    </GoopSidebarProvider>
  )
}
```

In Next.js, read the `sidebar_state` cookie in your layout and pass it on, as shadcn does: `<GoopSidebarProvider defaultOpen={(await cookies()).get('sidebar_state')?.value !== 'false'}>`.
::

The parts are `GoopSidebarProvider`, `GoopSidebar`, `GoopSidebarTrigger`, `GoopSidebarRail`, `GoopSidebarInset`, `GoopSidebarHeader`, `GoopSidebarFooter`, `GoopSidebarContent`, `GoopSidebarGroup` (with `Label`, `Action`, `Content`), `GoopSidebarMenu` (with `Item`, `Button`, `Action`, `Badge`, `Skeleton`, `Sub`, `SubItem`, `SubButton`), `GoopSidebarSeparator`, and `GoopSidebarInput`. `useSidebar()` returns `state`, `open`, `setOpen`, `isMobile`, `openMobile`, `setOpenMobile`, and `toggleSidebar`.

## Behavior

::fw
#vue
- **Highlight.** Hovering or tabbing through the menu moves one goo blob between the items. It travels with momentum, stretches a little, and its soft swell follows the cursor along the item (`highlight`, `followPointer`).
- **Active item.** The active item is a soft filled pill with a hint of the accent and a faint rim (`pill`).
- **Edge slosh.** When the sidebar collapses or expands, its inner edge is goo with inertia. A collapse pushes low, wide mounds out of the edge while it moves and lets them slosh back. An expand lands with a gentle overshoot. The mounds are placed differently every time, and at rest the edge is the sidebar's own (`slosh`).
- **Sub-menus.** A `GoopCollapsible` inside the sidebar springs its sub-menu open (`submenus`). The open row keeps shadcn's look, just the chevron turned, so only the active item wears the pill. Set `flood` on the collapsible to fill the row anyway.
- **Icon mode.** Collapsed to icons, each button's `tooltip` is a `GoopTooltip` that blooms beside it (`tooltips`).
- **Mobile.** Below 768px the sidebar is a sheet that blooms from the middle of its screen edge (`bloom`).
- **No layout cost.** The goo is drawn on `aria-hidden` layers behind the real content. It never changes the page's scroll size.

#react
- **Highlight.** Hovering or tabbing through the menu moves one goo blob between the items. It travels with momentum, stretches a little, and its soft swell follows the cursor along the item (`highlight`, `followPointer`).
- **Active item.** The active item is a soft filled pill with a hint of the accent and a faint rim (`pill`).
- **Travel.** Collapse and expand move like the Drawer: a fast launch into a small landing overshoot, and a collapse that accelerates away (`travel`).
- **Edge slosh.** When the sidebar collapses or expands, its inner edge is goo with inertia. A collapse pushes low, wide mounds out of the edge while it moves and lets them slosh back. An expand lands with a gentle overshoot. On `inset` the mounds start over the inset card's edge. At rest the edge is the sidebar's own (`slosh`).
- **Sub-menus.** A goo `GoopCollapsible` springs its sub-menu open, and the sidebar keeps the open row unfilled, just the chevron turned, so only the active item wears the pill (`submenus`). Its guide line pours down behind a goo bead as it opens (`pour`).
- **Mobile.** Below 768px the sidebar is a `GoopDrawer` from its side: panel and goo move as one body, land with a small overshoot and swipe closed (`drawer`). With `drawer={false}` it's shadcn's Sheet.
- **Icon mode.** Collapsed to icons, each button's `tooltip` is shadcn's tooltip beside it.
- **No layout cost.** The goo is drawn on `aria-hidden` layers behind the real content, after hydration. It never changes the page's scroll size, and the server renders shadcn's markup.
::

## Turning effects off

Every effect is a prop on `GoopSidebar`:

::fw
#vue
```vue
<GoopSidebar :slosh="false" />
<GoopSidebar :slosh="1.6" preset="wild" />
<GoopSidebar :highlight="false" :pill="false" />
<GoopSidebar :goo="false" />
```

#react
```tsx
<GoopSidebar slosh={false} />
<GoopSidebar slosh={1.6} preset="wild" />
<GoopSidebar highlight={false} pill={false} />
<GoopSidebar goo={false} />
```
::

## Accessibility

::fw
#vue
Keyboard focus, the Ctrl/Cmd+B shortcut, the mobile sheet's focus trap, and the tooltips come from the same reka-ui primitives as shadcn-vue. Every goo layer is `aria-hidden` and can't be clicked, and text is never filtered. Under reduced motion the edge doesn't slosh, the highlight snaps between items, and the sheet, tooltips, and sub-menus open plainly. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Keyboard focus, the Ctrl/Cmd+B shortcut, the mobile drawer's focus trap, and the tooltips come from the same Radix primitives as shadcn/ui. Every goo layer is `aria-hidden` and can't be clicked, and text is never filtered. Under reduced motion the edge doesn't slosh, the highlight snaps between items, collapse and expand are shadcn's linear, and sub-menus open plainly. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
