#vue
`GoopSheet` wraps the same [reka-ui Dialog](https://reka-ui.com/docs/components/dialog) primitive as shadcn-vue's Sheet, with the same API. Focus trapping, scroll locking, and dismissal work the same. Swap the imports and you're done.

#react
`GoopSheet` wraps the same [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) primitive as shadcn/ui's Sheet, with the same API and classes. Focus trapping, scroll locking, and dismissal work the same. Swap the imports and you're done.

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopSheet*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--popover`, `--popover-foreground`, `--foreground`, `--muted-foreground`, `--ring`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). It needs Tailwind CSS v4 and the shadcn tokens (`--popover`, `--popover-foreground`, `--foreground`, `--muted-foreground`, `--ring`).

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopButton,
  GoopSheet,
  GoopSheetClose,
  GoopSheetContent,
  GoopSheetDescription,
  GoopSheetFooter,
  GoopSheetHeader,
  GoopSheetTitle,
  GoopSheetTrigger,
} from '@goopui/vue'
</script>

<template>
  <GoopSheet>
    <GoopSheetTrigger as-child>
      <GoopButton variant="outline">Open sheet</GoopButton>
    </GoopSheetTrigger>
    <GoopSheetContent>
      <GoopSheetHeader>
        <GoopSheetTitle>Edit profile</GoopSheetTitle>
        <GoopSheetDescription>Make changes to your profile here.</GoopSheetDescription>
      </GoopSheetHeader>
      <GoopSheetFooter>
        <GoopSheetClose as-child>
          <GoopButton>Save changes</GoopButton>
        </GoopSheetClose>
      </GoopSheetFooter>
    </GoopSheetContent>
  </GoopSheet>
</template>
```

## Behavior

- **Open.** A blob appears at the middle of the sheet's screen edge and spreads in lobes until it fills the sheet. It overshoots the inner edge and wobbles to rest (`wobble`, `openSlosh`).
- **Splash.** Globs, drops, and specks fling off the inner edge and the sides, fall, and fade. None are thrown off-screen (`openDrips`). Then nothing moves.
- **Close.** The goo pulls in, wobbles, and shrinks back into the edge (`closeSlosh`). The overlay fades out over the same time.
- **Content stays sharp.** Only the sheet's background, border, and shadow are goo. They're drawn on an `aria-hidden` surface behind your content, so text and inputs are never filtered.
- **Canvas by default.** A sheet is a big surface, so it draws with the canvas renderer unless a prop or the app config says otherwise.

## Splash knobs

The bloom and its splash take the same knobs as [Dialog](/docs/components/dialog). `bloomStart="merge"` starts from a few drops that fuse instead of one. The four numeric props only matter while `openDrips` is on:

- `openDripAmount` (0 to 3): how many drops.
- `openDripSize` (0.3 to 2.5): how big.
- `openDripFling` (0 to 3): how far they fly.
- `openDripVariety` (0 to 1): the mix of big globs and specks. 0 makes them all alike.

`sloshVariety` (0 to 1) sets how differently each side bulges. 0 is an even, centred bulge.

::preview{:controls="false"}

<GoopSheetContent bloom-start="merge" :open-drip-amount="2" :open-drip-size="1.6" :open-drip-fling="2">

<GoopSheetContent :open-drips="false">...</GoopSheetContent>
```

<GoopSheetContent openDrips={false}>...</GoopSheetContent>
```
::

`openSlosh`, `openDrips`, and `closeSlosh` take `true`, `false`, or a strength from 0 to 2.

## Driving it from code

::fw
#vue
`GoopSheetContent` exposes its engine handle as `handle` (`null` before it mounts, or when `goo` is off). The panel only exists while open.

#react
`GoopSheetContent`'s `goopRef` receives its engine handle (`null` before it mounts, or when `goo` is off). The panel only exists while open; `ref` is the panel element, as in shadcn/ui.

## Accessibility

::fw
#vue
Focus trapping, scroll locking, Escape and outside-click dismissal, and ARIA attributes come from reka-ui. The goo surface is `aria-hidden` and can't be clicked, and your content is never filtered. Under reduced motion the sheet opens and closes plainly: it keeps its goo color, but the bloom, slosh, splash, and wobble are all turned off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Focus trapping, scroll locking, Escape and outside-click dismissal, and ARIA attributes come from Radix. The goo surface is `aria-hidden` and can't be clicked, and your content is never filtered. Under reduced motion the sheet opens and closes plainly: it keeps its goo color, but the bloom, slosh, splash, and wobble are all turned off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
::
