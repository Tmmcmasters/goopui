#vue
`GoopResizablePanelGroup`, `GoopResizablePanel` and `GoopResizableHandle` are shadcn-vue's Resizable parts on reka-ui's [`Splitter`](https://reka-ui.com/docs/components/splitter), with the same API (`direction`, `default-size`, `with-handle`) and shadcn's current classes. Swap the imports and you're done.

#react
`GoopResizablePanelGroup`, `GoopResizablePanel` and `GoopResizableHandle` are shadcn/ui's Resizable parts on [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels), with the same API (`orientation`, `defaultSize`, `withHandle`) and the same classes. `@goopui/react` depends on `react-resizable-panels`, so there's nothing else to install. All three are client components, like shadcn's. `ref` is the DOM element (react-resizable-panels' `elementRef`).
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopResizable*` part.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Resizable parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopResizableHandle, GoopResizablePanel, GoopResizablePanelGroup } from '@goopui/vue'
</script>

<template>
  <GoopResizablePanelGroup direction="horizontal" class="max-w-md rounded-lg border">
    <GoopResizablePanel :default-size="50">
      <div class="flex h-[200px] items-center justify-center p-6">
        <span class="font-semibold">One</span>
      </div>
    </GoopResizablePanel>
    <GoopResizableHandle with-handle />
    <GoopResizablePanel :default-size="50">
      <GoopResizablePanelGroup direction="vertical">
        <GoopResizablePanel :default-size="25">
          <div class="flex h-full items-center justify-center p-6">
            <span class="font-semibold">Two</span>
          </div>
        </GoopResizablePanel>
        <GoopResizableHandle with-handle />
        <GoopResizablePanel :default-size="75">
          <div class="flex h-full items-center justify-center p-6">
            <span class="font-semibold">Three</span>
          </div>
        </GoopResizablePanel>
      </GoopResizablePanelGroup>
    </GoopResizablePanel>
  </GoopResizablePanelGroup>
</template>
```

#react
```tsx
import { GoopResizableHandle, GoopResizablePanel, GoopResizablePanelGroup } from '@goopui/react'

export function Panels() {
  return (
    <GoopResizablePanelGroup orientation="horizontal" className="max-w-md rounded-lg border">
      <GoopResizablePanel defaultSize="50%">
        <div className="flex h-[200px] items-center justify-center p-6">
          <span className="font-semibold">One</span>
        </div>
      </GoopResizablePanel>
      <GoopResizableHandle withHandle />
      <GoopResizablePanel defaultSize="50%">
        <GoopResizablePanelGroup orientation="vertical">
          <GoopResizablePanel defaultSize="25%">
            <div className="flex h-full items-center justify-center p-6">
              <span className="font-semibold">Two</span>
            </div>
          </GoopResizablePanel>
          <GoopResizableHandle withHandle />
          <GoopResizablePanel defaultSize="75%">
            <div className="flex h-full items-center justify-center p-6">
              <span className="font-semibold">Three</span>
            </div>
          </GoopResizablePanel>
        </GoopResizablePanelGroup>
      </GoopResizablePanel>
    </GoopResizablePanelGroup>
  )
}
```
::

Set the goo props on `GoopResizablePanelGroup`; its handles follow them (a prop set on a `GoopResizableHandle` wins there).

## What it does

- **bulge.** While you drag, the grip is a goo bead: it swells a little and its leading side rises in a low, wide mound toward the drag, deeper the faster you go, while the trailing side draws in. No sharp knob, just a soft lean.
- **wobble.** Let go and the bead wobbles back to rest like jelly, once or twice. Turn it off and it eases back instead.
- **No grip.** Without `with-handle` / `withHandle` the same mound rises on the divider line itself, under the pointer.
- **Cheap.** One `aria-hidden` SVG path in the handle, drawn only while you drag or it settles. Nothing runs at rest.
- **No layout shift.** The bead is painted over the panels without moving them, and never changes the page's scroll size.
- **Reduced motion.** A plain handle.
- **Server render.** SSR renders shadcn's markup; the goo starts in the browser.

## Props

::component-props{name="resizable"}
::

::fw
#vue
`GoopResizablePanelGroup` also takes reka's `direction`, `auto-save-id`, `keyboard-resize-by` and the layout events. `GoopResizableHandle` takes the same goo props (they win over the group's), `with-handle`, `disabled` and `class`, and exposes `handle` (the live `ResizableHandle`). `GoopResizablePanel` is reka's `SplitterPanel`.

#react
`GoopResizablePanelGroup` also takes react-resizable-panels' `orientation`, `defaultLayout` and the layout callbacks. `GoopResizableHandle` takes the same goo props (they win over the group's), `withHandle`, `disabled` and `className`; `goopRef` receives the live `ResizableHandle` (`null` before mount or with the goo off). `GoopResizablePanel` is react-resizable-panels' `Panel`.
::

## Accessibility

Same markup and keyboard behaviour as shadcn: the handle is a focusable `separator` you move with the arrow keys. The bead is `aria-hidden` and still under reduced motion. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
