`GoopNumberField` is shadcn-vue's NumberField on reka-ui's `NumberFieldRoot`: the same parts (`GoopNumberFieldContent`, `GoopNumberFieldInput`, `GoopNumberFieldIncrement`, `GoopNumberFieldDecrement`), the same classes, `v-model`, and `class` merge. `min`, `max`, `step`, `formatOptions`, `locale`, `disabled`, `id`, `name`, and the other reka props go straight to reka. The goo is drawn on `aria-hidden` layers inside `GoopNumberFieldContent`, behind the real input and buttons.

## Installation

Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every part. They use the same shadcn tokens as the plain NumberField (`--input`, `--ring`, `--accent`, `--destructive`).

## Usage

```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopNumberField,
  GoopNumberFieldContent,
  GoopNumberFieldDecrement,
  GoopNumberFieldIncrement,
  GoopNumberFieldInput,
} from '@goopui/vue'

const qty = ref(3)
</script>

<template>
  <label for="qty" class="text-sm font-medium">Quantity</label>
  <GoopNumberField id="qty" v-model="qty" :min="0" :max="20">
    <GoopNumberFieldContent>
      <GoopNumberFieldDecrement />
      <GoopNumberFieldInput />
      <GoopNumberFieldIncrement />
    </GoopNumberFieldContent>
  </GoopNumberField>
</template>
```

## What it does

Each part is an effect you can turn off:

- **squish.** Pressing + or - swells a soft goo dollop out of the button, squished low and wide. Letting go springs it back with a small wobble as it shrinks away.
- **nudge.** Every step (a press, a held repeat, or an arrow key) shoves the dollop toward the side you pressed and sends a ripple along the ring from that side. A typed value that commits on blur doesn't nudge.
- **The focus ring.** The same ring as [Input](/docs/components/input), with the same `flow`, `close`, `ripple`, `wobble`, `drain`, `drip`, and `drips` effects. A press on a button focuses the field, so the ring flows in from that button's side.

## Formatting

`formatOptions` and `locale` work as in reka, so currency, percent, and unit fields need no extra code.

::preview{:controls="false"}
:demo-number-field{set="currency"}
::

```vue
<GoopNumberField v-model="price" :step="0.5" :format-options="{ style: 'currency', currency: 'USD' }">
  <GoopNumberFieldContent>
    <GoopNumberFieldDecrement />
    <GoopNumberFieldInput />
    <GoopNumberFieldIncrement />
  </GoopNumberFieldContent>
</GoopNumberField>
```

## Effects and presets

Every effect is a prop on `GoopNumberField`. `false` turns it off, `true` uses the preset's strength, and a number scales it.

::preview{:controls="false"}
:demo-number-field{set="effects"}
::

```vue
<GoopNumberField preset="wild">...</GoopNumberField>
<GoopNumberField :squish="false" :nudge="false">...</GoopNumberField>
```

## Disabled and goo off

A disabled field is shadcn's: dimmed, and its buttons don't press, so nothing squishes. `:goo="false"` renders a plain shadcn NumberField.

## Colors

| Variable | Default | What it colors |
| --- | --- | --- |
| `--goop-number-field-press` | `var(--accent)` | The dollop under a pressed button. |
| `--goop-number-field-press-opacity` | `1` | Its opacity. |
| `--goop-input-color` | `var(--ring)` | The focus ring. |
| `--goop-input-opacity` | `0.5` | The focus ring's opacity. |
| `--goop-input-invalid-color` | `var(--destructive)` | The ring and drip of an invalid field. |

## Props

::component-props{name="number-field"}

`GoopNumberFieldContent` exposes `handle` (the live goo handle, `null` before mount or with `goo` off) and `el`. Before it mounts, during SSR, and with `:goo="false"`, the field looks exactly like shadcn's, so first paint and hydration match.

## Accessibility

It's reka's NumberField: the input is a `role="spinbutton"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`, the buttons are labelled "Increase" and "Decrease", and the arrow, Page Up/Down, Home, and End keys step the value. The goo layers are `aria-hidden` and can't be clicked. With the goo attached, shadcn's focus ring steps aside for the goo ring, which shows on every focus, keyboard included.

Under reduced motion the ring is a static closed band, a pressed button shows a still, round dollop, and steps don't nudge. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
