`GoopSeparator` wraps reka-ui's [`Separator`](https://reka-ui.com/docs/components/separator), like shadcn-vue's Separator, with the same classes. It has no goo: a line should stay a line.

## Installation

Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopSeparator`.

## Usage

```vue
<GoopSeparator class="my-4" />
<div class="flex h-5 items-center gap-4">
  <span>Blog</span>
  <GoopSeparator orientation="vertical" />
  <span>Docs</span>
</div>
```

## Props

`orientation` (`'horizontal'` by default, or `'vertical'`), `decorative` (`true` by default: hidden from assistive tech; `false` gives it `role="separator"`), `as`, `asChild`, and `class`.
