## Installation

::fw
#vue
`GoopToaster` wraps [vue-sonner](https://vue-sonner.vercel.app), the same library behind [shadcn-vue's Sonner](https://www.shadcn-vue.com/docs/components/sonner). `@goopui/vue` installs vue-sonner itself; add it to your app too, because your code imports `toast()` from it:

```bash
pnpm add vue-sonner
```

### Nuxt

```bash
pnpm add @goopui/nuxt vue-sonner
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
  css: ['vue-sonner/style.css'],
})
```

The module auto-imports `GoopToaster`, adds `goop.css`, and keeps a single copy of vue-sonner, so the toaster and your `toast()` calls share one queue.

### Vue

```bash
pnpm add @goopui/vue vue-sonner
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
@import "vue-sonner/style.css";
```

#react
`GoopToaster` wraps [sonner](https://sonner.emilkowal.ski), the same library behind [shadcn/ui's Sonner](https://ui.shadcn.com/docs/components/sonner). `@goopui/react` installs sonner itself; add it to your app too, because your code imports `toast()` from it (keep it on the same major version, so the toaster and your `toast()` calls share one queue):

```bash
pnpm add @goopui/react sonner
```

Add the stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page. sonner injects its own CSS, so there is nothing else to import.
::

## Usage

::fw
#vue
Mount `GoopToaster` once, near the root of your app. Then call `toast()` from vue-sonner anywhere, the same as with shadcn-vue's Sonner:

```vue [app.vue]
<script setup lang="ts">
// Nuxt auto-imports GoopToaster. In plain Vue, import it:
import { GoopToaster } from '@goopui/vue'
</script>

<template>
  <NuxtPage />
  <GoopToaster />
</template>
```

```vue
<script setup lang="ts">
import { toast } from 'vue-sonner'
</script>

<template>
  <GoopButton variant="outline" @click="toast('Event has been created')">
    Show toast
  </GoopButton>
</template>
```

`GoopToaster` takes every vue-sonner `Toaster` prop (`position`, `expand`, `richColors`, `closeButton`, `duration`, `toastOptions`, ...). Its defaults match shadcn's: the popover tokens for color, `rounded-2xl` toasts, and lucide icons.

#react
Mount `GoopToaster` once, near the root of your app (in Next.js, the root layout). Then call `toast()` from sonner anywhere, the same as with shadcn/ui's Sonner:

```tsx [app/layout.tsx]
import { GoopToaster } from '@goopui/react'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {children}
        <GoopToaster />
      </body>
    </html>
  )
}
```

```tsx
'use client'
import { GoopButton } from '@goopui/react'
import { toast } from 'sonner'

export function SaveButton() {
  return (
    <GoopButton variant="outline" onClick={() => toast('Event has been created')}>
      Show toast
    </GoopButton>
  )
}
```

`GoopToaster` takes every sonner `Toaster` prop (`position`, `expand`, `richColors`, `closeButton`, `duration`, `toastOptions`, `theme`, ...). Its defaults match shadcn's: the popover tokens for color, `rounded-2xl` toasts, and lucide icons.
::

## Calling toast()

::fw
#vue
There is no goopUI `toast`. Use vue-sonner's, with all its options.

```ts
import { toast } from 'vue-sonner'

toast('Event has been created')
toast('Event has been created', { description: 'Sunday, December 03, 2023 at 9:00 AM' })
toast.success('Changes saved')
toast.error('Could not reach the server')
toast.info('A new version is available')
toast.warning('Your trial ends tomorrow')

toast('Message archived', {
  action: { label: 'Undo', onClick: () => toast('Restored') },
})

toast.promise(save(), {
  loading: 'Saving...',
  success: (data) => `${data.name} has been added`,
  error: 'Something went wrong',
})
```

The [vue-sonner docs](https://vue-sonner.vercel.app) cover the rest: custom components, durations, dismissing, multiple toasters with `toasterId`.

#react
There is no goopUI `toast`. Use sonner's, with all its options.

```ts
import { toast } from 'sonner'

toast('Event has been created')
toast('Event has been created', { description: 'Sunday, December 03, 2023 at 9:00 AM' })
toast.success('Changes saved')
toast.error('Could not reach the server')
toast.info('A new version is available')
toast.warning('Your trial ends tomorrow')

toast('Message archived', {

})

toast.promise(save(), {
  loading: 'Saving...',

})
```

The [sonner docs](https://sonner.emilkowal.ski) cover the rest: custom JSX toasts, durations, dismissing, multiple toasters with `id`.

## Behavior

All the goo for a stack is drawn in one `aria-hidden` layer behind the toasts. The toasts stay real, unfiltered DOM, so text, buttons, and focus work as in Sonner. Each toast's own background, border, and shadow are handed to the goo layer.

- **Drop in** (`dropIn`). A new toast arrives as a round blob at the toaster's edge and inflates into the toast. It overshoots, trails goo back toward the edge until the trail snaps, then the far side sloshes.
- **Merge** (`merge`). Stacked toasts are joined by fat goo necks where they touch. Hover the stack to expand it and the necks stretch, thin, and snap. Collapse it and they form again.
- **Drips** (`drips`). A toast that leaves sags and pinches while a few drops neck off its bottom edge and fall. Swipe one away and the drops fly the way you swiped.
- **Layout** never changes. The goo layer is fixed behind the toaster, and the filter only covers the stack's bounding box.

## Props

::fw
#vue
`GoopToaster` takes vue-sonner's `Toaster` props plus `class`, and adds the goo props.

#react
`GoopToaster` takes sonner's `Toaster` props plus `className`, and adds the goo props. Its `ref` is sonner's `<section>`.
::

::component-props{name="toaster"}
::

::fw
#vue
Effect props take `true`, `false`, or a number from 0 to 2. Props win over the app-wide config (`GoopPlugin` or the module options), which wins over the preset.

```vue
<GoopToaster position="top-center" preset="wild" :drips="false" />
```

`GoopToaster` also exposes `handle`, the core `ToasterHandle` (`null` before mount or with `goo` off). `handle.refresh()` re-scans the toasts and redraws.

#react
Effect props take `true`, `false`, or a number from 0 to 2. Props win over `<GoopProvider>`, which wins over the preset.

```tsx
<GoopToaster position="top-center" preset="wild" drips={false} />
```

`goopRef` receives the core `ToasterHandle` (`null` before mount or with `goo` off). `handle.refresh()` re-scans the toasts and redraws.
::

## Colors

Toasts use shadcn's popover tokens, and the goo paints whatever background the toast has: `--popover` by default, the status colors with `richColors`, or a class you set through `toastOptions`. Change the tokens and the goo follows, in light and dark mode.

## Accessibility

Sonner's live region and focus handling are untouched, because the toasts are the real elements. The goo layer is `aria-hidden` and ignores the pointer. Under reduced motion the toasts keep their goo bodies and the effects turn off: no drop in, no necks stretching, no drips. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
