::fw
#vue
`GoopAvatar`, `GoopAvatarImage`, and `GoopAvatarFallback` wrap reka-ui's [`AvatarRoot`](https://reka-ui.com/docs/components/avatar), `AvatarImage`, and `AvatarFallback`, like shadcn-vue's Avatar. Image loading, `delayMs`, and the fallback swap all come from reka-ui.

#react
`GoopAvatar`, `GoopAvatarImage`, and `GoopAvatarFallback` wrap [Radix Avatar](https://www.radix-ui.com/primitives/docs/components/avatar)'s Root, Image, and Fallback, like shadcn/ui's Avatar, with its `size` prop. Image loading, `delayMs`, and the fallback swap all come from Radix. shadcn's `GoopAvatarBadge`, `GoopAvatarGroup`, and `GoopAvatarGroupCount` are here too.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports all three.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Avatar parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopAvatar, GoopAvatarFallback, GoopAvatarImage } from '@goopui/vue'
</script>

<template>
  <GoopAvatar>
    <GoopAvatarImage src="/me.png" alt="Tim McMasters" />
    <GoopAvatarFallback>TM</GoopAvatarFallback>
  </GoopAvatar>
</template>
```

#react
```tsx
import { GoopAvatar, GoopAvatarFallback, GoopAvatarImage } from '@goopui/react'

export function Me() {
  return (
    <GoopAvatar>
      <GoopAvatarImage src="/me.png" alt="Tim McMasters" />
      <GoopAvatarFallback>TM</GoopAvatarFallback>
    </GoopAvatar>
  )
}
```
::

## What it does

::fw
#vue
- **settle.** reka-ui renders the image only once it has loaded. When it appears (and when the fallback appears), it scales in from about 80%, overshoots by a few percent with a slight squash, rebounds, and settles. It plays once per appearance.

#react
- **settle.** Radix renders the image only once it has loaded. When it appears (and when the fallback appears), it scales in from about 80%, overshoots by a few percent with a slight squash, rebounds, and settles. It plays once per appearance.
::

It's a single CSS animation on a transform, with no script. While the settle is on, the avatar lets the overshoot show past its circle, and the image rounds its own corners.

::fw
#vue
Turn it off with `:settle="false"`, or scale the overshoot with a number.

#react
Turn it off with `settle={false}`, or scale the overshoot with a number.
::

## Props

::component-props{name="avatar"}
::

::fw
#vue
`GoopAvatarImage` takes reka-ui's `src`, `referrerPolicy`, and `crossOrigin`, and emits `loadingStatusChange`. `GoopAvatarFallback` takes `delayMs`, `as`, and `asChild`. Both take `class`.

#react
`GoopAvatarImage` takes Radix's `src`, `alt`, and `onLoadingStatusChange`. `GoopAvatarFallback` takes `delayMs` and `asChild`. All the parts take `className`. Only `GoopAvatar` is a client component; the other parts render in Server Components.
::

## Accessibility

Give the image an `alt`. Under reduced motion the avatar appears at once, without the settle. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
