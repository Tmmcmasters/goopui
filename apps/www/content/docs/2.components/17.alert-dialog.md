#vue
`GoopAlertDialog` wraps the same [reka-ui AlertDialog](https://reka-ui.com/docs/components/alert-dialog) primitive as shadcn-vue's AlertDialog, with the same API. It interrupts the user and waits for a response. Swap the imports and you're done.

#react
`GoopAlertDialog` wraps the same [Radix AlertDialog](https://www.radix-ui.com/primitives/docs/components/alert-dialog) primitive as shadcn/ui's AlertDialog, with the same API and classes. It interrupts the user and waits for a response. Swap the imports and you're done.
::

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopAlertDialog*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens.

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). It needs Tailwind CSS v4 and the shadcn tokens (`--popover`, `--popover-foreground`, `--muted`, `--muted-foreground`, `--border`, `--radius`), plus the [Button](/docs/components/button#installation)'s for Action and Cancel.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopAlertDialog,
  GoopAlertDialogAction,
  GoopAlertDialogCancel,
  GoopAlertDialogContent,
  GoopAlertDialogDescription,
  GoopAlertDialogFooter,
  GoopAlertDialogHeader,
  GoopAlertDialogTitle,
  GoopAlertDialogTrigger,
  GoopButton,
} from '@goopui/vue'
</script>

<template>
  <GoopAlertDialog>
    <GoopAlertDialogTrigger as-child>
      <GoopButton variant="outline">Delete account</GoopButton>
    </GoopAlertDialogTrigger>
    <GoopAlertDialogContent>
      <GoopAlertDialogHeader>
        <GoopAlertDialogTitle>Are you absolutely sure?</GoopAlertDialogTitle>
        <GoopAlertDialogDescription>This action cannot be undone.</GoopAlertDialogDescription>
      </GoopAlertDialogHeader>
      <GoopAlertDialogFooter>
        <GoopAlertDialogCancel>Cancel</GoopAlertDialogCancel>
        <GoopAlertDialogAction>Continue</GoopAlertDialogAction>
      </GoopAlertDialogFooter>
    </GoopAlertDialogContent>
  </GoopAlertDialog>
</template>
```

#react
```tsx

        </GoopAlertDialogHeader>
        <GoopAlertDialogFooter>

          <GoopAlertDialogAction>Continue</GoopAlertDialogAction>
        </GoopAlertDialogFooter>
      </GoopAlertDialogContent>

```

All the panel's goo lives on `GoopAlertDialogContent`.

`GoopAlertDialogAction` and `GoopAlertDialogCancel` render as a `GoopButton` (default and outline variants), so they drip too. `variant`, `size`, and `goo` pass through to the button.

`GoopAlertDialogContent` takes shadcn's `size`: `'default'`, or `'sm'` for a narrower panel with a two-column footer. `GoopAlertDialogMedia` is shadcn's icon tile, placed in the header beside (or above) the title.

## Behavior

The panel blooms from its own center, exactly like the [Dialog](/docs/components/dialog)'s, with every toggle and knob the Dialog has. Only the defaults differ:

- **A lighter slosh.** `openSlosh` is `0.6` and `closeSlosh` is `0.7` when you leave them alone (or pass `true`).
- **A smaller splash.** A few small drops, flung a short way: `openDripAmount` `0.35`, `openDripSize` `0.75`, `openDripFling` `0.6`.
- **Content stays sharp.** The goo is drawn on an `aria-hidden` surface behind your content.

Turn any of it up, or off:

```vue

<GoopAlertDialogContent

  :open-drip-amount="1" :open-drip-size="1" :open-drip-fling="1"
  overlay
>
  ...
</GoopAlertDialogContent>
```

```tsx

<GoopAlertDialogContent
```

## Goo overlay

Like the Dialog's, the goo overlay is opt-in: set `overlay` and the backdrop pours down over the page and drains off on close. `overlayDrips` shapes its leading edge. See [Dialog: Goo overlay](/docs/components/dialog#goo-overlay).

## Accessibility

::fw
#vue
Focus trapping (Cancel gets the initial focus), scroll locking, and the `alertdialog` role come from reka-ui. The goo surface is `aria-hidden` and can't be clicked, and your content is never filtered. Under reduced motion it opens and closes plainly: the panel keeps its goo shape and color, but the bloom, slosh, splash, and wobble are all turned off, and the goo overlay appears without pouring. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Focus trapping (Cancel gets the initial focus), scroll locking, and the `alertdialog` role come from Radix. The goo surface is `aria-hidden` and can't be clicked, and your content is never filtered. Under reduced motion it opens and closes plainly: the panel keeps its goo shape and color, but the bloom, slosh, splash, and wobble are all turned off, and the goo overlay appears without pouring. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
