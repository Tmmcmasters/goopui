#react

The header, title, description and content have no `'use client'`, so they render in Server Components; `GoopEmpty` and `GoopEmptyMedia` are client components, because they carry the puddle.

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopEmpty*` part.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Empty parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopButton,
  GoopEmpty,
  GoopEmptyContent,
  GoopEmptyDescription,
  GoopEmptyHeader,
  GoopEmptyMedia,
  GoopEmptyTitle,
} from '@goopui/vue'
import { FolderIcon } from '@lucide/vue'
</script>

<template>
  <GoopEmpty>
    <GoopEmptyHeader>
      <GoopEmptyMedia variant="icon">
        <FolderIcon />
      </GoopEmptyMedia>
      <GoopEmptyTitle>No Projects Yet</GoopEmptyTitle>
      <GoopEmptyDescription>
        You haven't created any projects yet. Get started by creating your first project.
      </GoopEmptyDescription>
    </GoopEmptyHeader>
    <GoopEmptyContent>
      <GoopButton>Create Project</GoopButton>
    </GoopEmptyContent>
  </GoopEmpty>
</template>
```

#react
```tsx
import {
  GoopButton,
  GoopEmpty,
  GoopEmptyContent,
  GoopEmptyDescription,
  GoopEmptyHeader,
  GoopEmptyMedia,
  GoopEmptyTitle,
} from '@goopui/react'
import { FolderIcon } from 'lucide-react'

export function NoProjects() {
  return (
    <GoopEmpty>
      <GoopEmptyHeader>
        <GoopEmptyMedia variant="icon">
          <FolderIcon />
        </GoopEmptyMedia>
        <GoopEmptyTitle>No Projects Yet</GoopEmptyTitle>
        <GoopEmptyDescription>
          You haven't created any projects yet. Get started by creating your first project.
        </GoopEmptyDescription>
      </GoopEmptyHeader>
      <GoopEmptyContent>
        <GoopButton>Create Project</GoopButton>
      </GoopEmptyContent>
    </GoopEmpty>
  )
}
```
::

Set the goo props on `GoopEmpty`; the media follows them (a prop set on `GoopEmptyMedia` wins there).

## What it does

- **puddle.** The media sits in a low, wide goo puddle of its own muted tone. The puddle's middle rises in a soft mound to meet the media, so the icon tile looks like it's settling into its own goo. The rim has a few low lobes, never a drip.
- **breathe.** The puddle breathes very slowly, about one pixel, every six seconds or so. Under reduced motion it stays still.
- **Cheap.** One `aria-hidden` SVG path behind the media, and a CSS animation. No script runs per frame.
- **No layout shift.** The puddle is painted past the media's box without growing it, and never changes the page's scroll size.
- **Server render.** SSR renders shadcn's markup; the puddle appears in the browser.

## Props

::component-props{name="empty"}
::

::fw
#vue
`GoopEmptyMedia` takes the same goo props (they win over the root's), `variant` and `class`, and exposes `handle`. The other parts take `class`.

#react
`GoopEmptyMedia` takes the same goo props (they win over the root's), `variant`, `className` and the `div` props; its `ref` is the media element and `goopRef` receives the live `EmptyPuddleHandle` (`null` before mount or with `goo` off). The other parts take `className` and their element's props.
::

## Accessibility

Same markup as shadcn. The puddle is `aria-hidden` and never moves under reduced motion. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
