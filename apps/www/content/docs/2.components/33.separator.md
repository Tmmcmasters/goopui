::fw
#vue
`GoopSeparator` wraps reka-ui's [`Separator`](https://reka-ui.com/docs/components/separator), like shadcn-vue's Separator, with the same classes. It has no goo: a line should stay a line.

#react
`GoopSeparator` wraps [Radix Separator](https://www.radix-ui.com/primitives/docs/components/separator), like shadcn/ui's Separator, with the same classes. It has no goo: a line should stay a line. It has no `'use client'` either, so it renders in Server Components.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopSeparator`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopSeparator` from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<GoopSeparator class="my-4" />
<div class="flex h-5 items-center gap-4">
  <span>Blog</span>
  <GoopSeparator orientation="vertical" />
  <span>Docs</span>
</div>
```

#react
```tsx
<GoopSeparator className="my-4" />
<div className="flex h-5 items-center gap-4">
  <span>Blog</span>
  <GoopSeparator orientation="vertical" />
```
