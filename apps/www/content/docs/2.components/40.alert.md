#react

Swap the imports and you're done. The title, description and action have no `'use client'`, so they render in Server Components; `GoopAlert` itself is a client component, because it plays the entrance.

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopAlert*` part.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Alert parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopAlert, GoopAlertDescription, GoopAlertTitle } from '@goopui/vue'
import { CircleCheckIcon } from '@lucide/vue'
</script>

<template>
  <GoopAlert>
    <CircleCheckIcon />
    <GoopAlertTitle>Success! Your changes have been saved</GoopAlertTitle>
    <GoopAlertDescription>This is an alert with icon, title and description.</GoopAlertDescription>
  </GoopAlert>
</template>
```

#react
```tsx
import { GoopAlert, GoopAlertDescription, GoopAlertTitle } from '@goopui/react'
import { CircleCheckIcon } from 'lucide-react'

export function SavedAlert() {
  return (
    <GoopAlert>
      <CircleCheckIcon />
      <GoopAlertTitle>Success! Your changes have been saved</GoopAlertTitle>
      <GoopAlertDescription>This is an alert with icon, title and description.</GoopAlertDescription>
    </GoopAlert>
  )
}
```

## What it does

::fw
#vue
- **bloom.** When the alert mounts, or appears (scrolled into view for the first time, or shown again after `v-show` hid it), its body blooms out of its top edge: it starts a little short, its bottom edge bulges in a low, wide mound as it travels, overshoots by a couple of pixels and settles flat. It takes about half a second.

#react
- **bloom.** When the alert mounts, or appears (scrolled into view for the first time, or shown again after being hidden with `display: none`), its body blooms out of its top edge: it starts a little short, its bottom edge bulges in a low, wide mound as it travels, overshoots by a couple of pixels and settles flat. It takes about half a second. A new React `key` remounts it, so it plays again.
::

- **wobble.** The icon gives one gentle jelly wobble as it arrives.
- **Nothing loops** and nothing is left behind. After the entrance the alert is a plain shadcn Alert again.
- **No layout shift.** The alert's box never moves: one `aria-hidden` path redraws its background and border while the entrance plays. Text is never filtered.
- **Server render.** SSR renders shadcn's markup; the entrance plays in the browser.

## Tuning

::preview{:controls="false"}
:demo-alert{set="plain"}
::

::fw
#vue
```vue
<GoopAlert preset="wild">...</GoopAlert>
<GoopAlert :bloom="false">...</GoopAlert>
<GoopAlert :goo="false">...</GoopAlert>
```

`bloom` and `wobble` take a number to scale them (`:bloom="0.5"`). `:goo="false"` renders exactly shadcn's Alert. The component exposes `replay()` to play the entrance again, for example when the message changes.

#react
```tsx
<GoopAlert preset="wild">...</GoopAlert>
<GoopAlert bloom={false}>...</GoopAlert>
<GoopAlert goo={false}>...</GoopAlert>
```

`bloom` and `wobble` take a number to scale them (`bloom={0.5}`). `goo={false}` renders exactly shadcn's Alert. To play the entrance again, for example when the message changes, pass a `goopRef` and call `replay()` on the `AlertHandle` (`null` before mount or with `goo` off), or change the alert's `key`:

```tsx
const alert = useRef<AlertHandle>(null)

<GoopAlert goopRef={alert}>...</GoopAlert>
<GoopButton onClick={() => alert.current?.replay()}>Replay</GoopButton>
```

## Props

::component-props{name="alert"}
::

::fw
#vue
`GoopAlertTitle`, `GoopAlertDescription` and `GoopAlertAction` take `class`.

#react
`GoopAlertTitle`, `GoopAlertDescription` and `GoopAlertAction` take `className` and the `div` props. On `GoopAlert`, `ref` is the alert element and `goopRef` receives the live `AlertHandle`.
::

## Accessibility

It keeps shadcn's `role="alert"`. The entrance layer is `aria-hidden`. Under reduced motion the alert appears at once, with no bloom or wobble. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
