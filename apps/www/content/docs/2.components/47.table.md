#vue
`GoopTable` has the same parts, markup and classes as shadcn-vue's Table: `GoopTableHeader`, `GoopTableBody`, `GoopTableFooter`, `GoopTableRow`, `GoopTableHead`, `GoopTableCell`, `GoopTableCaption` and `GoopTableEmpty`. Swap the imports and you're done.

#react
`GoopTable` has the same parts, markup and classes as shadcn/ui's Table: `GoopTableHeader`, `GoopTableBody`, `GoopTableFooter`, `GoopTableRow`, `GoopTableHead`, `GoopTableCell` and `GoopTableCaption`, plus `GoopTableEmpty` (shadcn-vue's empty row, kept for parity). Swap the imports and you're done. Only `GoopTable` is a client component; the other parts have no `'use client'` and render in Server Components.

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopTable*` part.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Table parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopTable, GoopTableBody, GoopTableCell, GoopTableHead, GoopTableHeader, GoopTableRow } from '@goopui/vue'
</script>

<template>
  <GoopTable>
    <GoopTableHeader>
      <GoopTableRow>
        <GoopTableHead>Invoice</GoopTableHead>
        <GoopTableHead class="text-right">Amount</GoopTableHead>
      </GoopTableRow>
    </GoopTableHeader>
    <GoopTableBody>
      <GoopTableRow v-for="row in invoices" :key="row.invoice">
        <GoopTableCell class="font-medium">{{ row.invoice }}</GoopTableCell>
        <GoopTableCell class="text-right">{{ row.amount }}</GoopTableCell>
      </GoopTableRow>
    </GoopTableBody>
  </GoopTable>
</template>
```

#react
```tsx
import { GoopTable, GoopTableBody, GoopTableCell, GoopTableHead, GoopTableHeader, GoopTableRow } from '@goopui/react'

export function Invoices({ invoices }: { invoices: { invoice: string; amount: string }[] }) {
  return (
    <GoopTable>
      <GoopTableHeader>
        <GoopTableRow>
          <GoopTableHead>Invoice</GoopTableHead>
          <GoopTableHead className="text-right">Amount</GoopTableHead>
        </GoopTableRow>
      </GoopTableHeader>
      <GoopTableBody>
        {invoices.map((row) => (
          <GoopTableRow key={row.invoice}>
            <GoopTableCell className="font-medium">{row.invoice}</GoopTableCell>
            <GoopTableCell className="text-right">{row.amount}</GoopTableCell>
          </GoopTableRow>
        ))}
      </GoopTableBody>
    </GoopTable>
  )
}
```
::

Set the goo props on `GoopTable`.

## What it does

- **One blob.** Hovering a body row lights it with a soft goo pill in shadcn's hover tone. Move down and the same blob glides to the next row, stretching a little with a short tail (`momentum`) and landing softly (`wobble`). Leaving the table lets it fade. Header and footer rows keep shadcn's look.
- **It follows the pointer.** A low, wide swell of the blob sits under the cursor (`followPointer`), like the menu highlight.
- **Never clipped, never in the way.** The blob is a pill inset a few pixels into the row and lives in a clipping layer the size of the table, so it never grows the table's scroll area (wide tables still scroll sideways as in shadcn) and nothing shifts.
- **No sticky hover on phones.** Touch never lights a row.
- **Server render.** SSR renders shadcn's markup; the blob attaches in the browser.

## Selected row

With `selected`, the blob rests on the selected row (`data-state="selected"`) when the pointer is elsewhere, and is that row's fill. Click a row:

::preview{:controls="false"}
:demo-table{set="selected"}
::

::fw
#vue
```vue
<GoopTable selected>
  <GoopTableBody>
    <GoopTableRow
      v-for="row in invoices"
      :key="row.invoice"
      :data-state="picked === row.invoice ? 'selected' : undefined"
      @click="picked = row.invoice"
    >
      ...
    </GoopTableRow>
  </GoopTableBody>
</GoopTable>
```

#react
```tsx
<GoopTable selected>
  <GoopTableBody>
    {invoices.map((row) => (
      <GoopTableRow
        key={row.invoice}
        data-state={picked === row.invoice ? 'selected' : undefined}
        onClick={() => setPicked(row.invoice)}
      >
        ...
      </GoopTableRow>
    ))}
  </GoopTableBody>
</GoopTable>
```
::

With several selected rows, the blob rests on the first; the others keep shadcn's flat fill.

## Props

::component-props{name="table"}
::

::fw
#vue
`GoopTable` exposes `handle`, the live row highlight handle. Every part takes `class`.

#react
`GoopTable`'s `ref` is the `<table>` and `goopRef` receives the live row highlight handle (a `TableHighlightHandle`, `null` before mount or with the blob off). Every part takes `className` and its element's props.
::

## Accessibility

Same as shadcn: a real `<table>` with header cells and a caption. The blob and its layer are `aria-hidden`. Under reduced motion the blob snaps to the row with no travel. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
