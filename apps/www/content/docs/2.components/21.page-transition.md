A thick band of goo pours in from one edge, slows over the middle of the screen, then flows on and out the far edge. Both of its edges are low, wide mounds that are different every time: the front leads with a little momentum and the trailing edge stretches back like poured goo. The page stays visible above and below the band for most of the run, so it never blacks out the screen.

The route changes while the band is over the middle. The new page fades in (about 200 ms) behind and around it, so the swap never pops. If the next page isn't ready yet, the band keeps creeping slowly while it waits.

A few bubbles of mixed sizes rise through the goo, against the way it pours. They're real holes, so you see the page through them. They wobble, squash a little as they speed up, and some merge. A bubble that reaches an edge pops into it: the edge dips where it popped, then relaxes. They're re-rolled every time and nothing is left behind.

## Nuxt

Turn it on in the module options. It's off by default.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
  goop: {
    pageTransition: true,
    // or: pageTransition: { direction: 'up', duration: 500 },
  },
})
```

Before each route change, navigation waits for the band to reach the middle of the screen. The reveal starts on `page:finish`, once the new page has rendered. If that never fires, it reveals after `timeout` ms (default 2000). Hash and query changes don't transition, and neither does the first load. The live handle is `useNuxtApp().$goopPageTransition`.

## Vue

With vue-router, pass the router to `GoopPageTransition` once, near the root:

```vue
<script setup lang="ts">
import { GoopPageTransition } from '@goopui/vue'
import { useRouter } from 'vue-router'

const router = useRouter()
</script>

<template>
  <GoopPageTransition :router="router" direction="down" />
  <RouterView />
</template>
```

Or drive it yourself with the composable. `cover()` resolves once the screen is covered, and `reveal()` resolves once it's gone:

```ts
import { useGoopPageTransition } from '@goopui/vue'

const goo = useGoopPageTransition({ direction: 'left' })

async function swap() {
  await goo.cover()
  await loadTheNextThing()
  await goo.reveal()
}
```

## Core

Without a framework, use `createPageTransition` from `@goopui/core`. It returns `{ cover, reveal, phase, update, destroy }`:

```ts
import { createPageTransition } from '@goopui/core'

const goo = createPageTransition({ direction: 'down' })
await goo.cover()
// swap the page
await goo.reveal()
```

## Colors

The goo reads `--goop-page-transition`, which falls back to `--primary`. Set `--goop-page-transition-accent` to give the edges and the bubbles a thin colored rim, and `--goop-page-transition-highlight` for a soft lighter glow through the middle of the band. This site uses Slime with a deep green rim:

```css
:root {
  --goop-page-transition: #1fa64a;
  --goop-page-transition-accent: oklch(0.43 0.12 150);
  --goop-page-transition-highlight: oklch(0.73 0.18 146);
}
```

The `color`, `accent` and `highlight` options override them. They take any CSS color or `var()`, and `accent: false` turns the lip off.

## Options

::component-props{name="page-transition"}
::

In Vue they're props on `GoopPageTransition` and options to `useGoopPageTransition`, and `goo: false` turns it off. In core, use `enabled: false` for the same thing.

The Nuxt module also takes `fade`, the element to fade in as the new page swaps in (default `'#__nuxt'`, or `false` for none), and `fadeDuration` (default 200 ms). With vue-router, `goopRouterTransition` takes the same `fade` option.

## Performance

The overlay is one fixed, full-screen SVG with one filled path, plus one more for the lip. Each frame rewrites that path from about 60 points for the band, plus 20 for each live bubble. The bubbles are holes cut in the same path (`fill-rule: evenodd`), not extra layers. There's no blur filter, canvas, or WebGL, so it's cheap on phones. Being `position: fixed`, it never changes the page's scroll size, and nothing is in the DOM until the first transition.

## Accessibility

The overlay is `aria-hidden`. It blocks clicks until the route has changed, so a double click can't start two navigations, and lets them through while it flows away. Focus and scroll are left to the router.

Under reduced motion there's no goo and no bubbles. The screen fades to the goo color and back in about 150 ms each way. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
