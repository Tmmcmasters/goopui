::fw
#vue
`GoopAccordion` wraps the same [reka-ui Accordion](https://reka-ui.com/docs/components/accordion) primitive as shadcn-vue's Accordion, with the same API. Keyboard navigation, `type="single"` / `"multiple"`, `collapsible`, and ARIA work the same. Swap the imports and you're done. [`GoopCollapsible`](#collapsible) is on this page too: it's the same goo on a single trigger.

#react
`GoopAccordion` wraps the same [Radix Accordion](https://www.radix-ui.com/primitives/docs/components/accordion) primitive as shadcn/ui's Accordion, with the same API. Keyboard navigation, `type="single"` / `"multiple"`, `collapsible`, and ARIA work the same. Swap the imports and you're done. [`GoopCollapsible`](#collapsible) is on this page too: it's the same goo on a single trigger.

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopAccordion*` and `GoopCollapsible*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--primary`, `--primary-foreground`, `--muted-foreground`, `--ring`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Accordion and Collapsible parts from `@goopui/react`. It needs Tailwind CSS v4 and the shadcn tokens (`--primary`, `--primary-foreground`, `--muted-foreground`, `--ring`).
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopAccordion,
  GoopAccordionContent,
  GoopAccordionItem,
  GoopAccordionTrigger,
} from '@goopui/vue'
</script>

<template>
  <GoopAccordion type="single" collapsible default-value="what" class="w-full">
    <GoopAccordionItem value="what">
      <GoopAccordionTrigger>What is goopUI?</GoopAccordionTrigger>
      <GoopAccordionContent>shadcn-vue components with gooey, dripping motion.</GoopAccordionContent>
    </GoopAccordionItem>
    <GoopAccordionItem value="motion">
      <GoopAccordionTrigger>Does it respect reduced motion?</GoopAccordionTrigger>
      <GoopAccordionContent>Yes.</GoopAccordionContent>
    </GoopAccordionItem>
  </GoopAccordion>
</template>
```

#react
```tsx
import { GoopAccordion, GoopAccordionContent, GoopAccordionItem, GoopAccordionTrigger } from '@goopui/react'

export function Faq() {
  return (
    <GoopAccordion type="single" collapsible defaultValue="what" className="w-full">
      <GoopAccordionItem value="what">
        <GoopAccordionTrigger>What is goopUI?</GoopAccordionTrigger>
        <GoopAccordionContent>shadcn/ui components with gooey, dripping motion.</GoopAccordionContent>
      </GoopAccordionItem>
      <GoopAccordionItem value="motion">
        <GoopAccordionTrigger>Does it respect reduced motion?</GoopAccordionTrigger>
        <GoopAccordionContent>Yes.</GoopAccordionContent>
      </GoopAccordionItem>
    </GoopAccordion>
  )
}
```

To control it, pass `value` and `onValueChange`, as with Radix.
::

The parts are `GoopAccordion`, `GoopAccordionItem`, `GoopAccordionTrigger`, and `GoopAccordionContent`. The goo props go on `GoopAccordion`, and every item follows them.

## Behavior

- **Flood.** Opening a row floods its trigger with goo from the click point (its center when you open it from the keyboard). The front crests against the walls, the row wobbles once it's full, and a few droplets splash off its top edge (`flood`, `wobble`, `droplets`). It's the same fill as the Toggle's.
- **Jelly content.** The content opens on a spring at the same time: it overshoots, then settles (`jelly`). It closes on a short spring with no overshoot.
- **Drain.** Closing a row drains the goo back into the click point. In a single accordion, the old row drains while the new one floods.
- **At rest** nothing animates. The open row just stays filled.
- **Content stays sharp.** The goo is one `aria-hidden` layer inside the trigger. Once the row is half full, the trigger's text and chevron switch to the goo's foreground color.
- **Layout** is shadcn's exactly. Closed rows look exactly like shadcn's.

## Tuning

Every effect takes `true`, `false`, or a strength from 0 to 2:

::preview{:controls="false"}
:demo-accordion{set="multiple"}
::

::fw
#vue
```vue
<GoopAccordion type="multiple" preset="wild" :droplets="2">...</GoopAccordion>
<GoopAccordion type="single" :flood="false" :jelly="0.5">...</GoopAccordion>
```

#react
```tsx
<GoopAccordion type="multiple" preset="wild" droplets={2}>...</GoopAccordion>
<GoopAccordion type="single" flood={false} jelly={0.5}>...</GoopAccordion>
```
::

The goo paints with `--goop-accordion-fill` (default `--primary`), and the flooded trigger's text uses `--goop-accordion-text` (default `--primary-foreground`). Set them on the accordion, or any parent, to recolor it.

## Collapsible

::fw
#vue
`GoopCollapsible` wraps reka-ui's Collapsible, like shadcn-vue's. It takes the same goo props as `GoopAccordion`: its trigger floods while it's open, and the content springs open.

#react
`GoopCollapsible` wraps Radix's Collapsible, like shadcn/ui's. It takes the same goo props as `GoopAccordion`: its trigger floods while it's open, and the content springs open.
::

::preview{caption="The trigger floods while it's open." :controls="false"}
:demo-accordion{set="collapsible"}
::

::fw
#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { GoopButton, GoopCollapsible, GoopCollapsibleContent, GoopCollapsibleTrigger } from '@goopui/vue'
const open = ref(false)
</script>

<template>
  <GoopCollapsible v-model:open="open" class="flex flex-col gap-2">
    <div class="flex items-center justify-between">
      <span>3 starred repositories</span>
      <GoopCollapsibleTrigger as-child>
        <GoopButton variant="outline" size="sm">{{ open ? 'Hide' : 'Show' }}</GoopButton>
      </GoopCollapsibleTrigger>
    </div>
    <div>goopui/core</div>
    <GoopCollapsibleContent class="flex flex-col gap-2">
      <div>goopui/vue</div>
      <div>goopui/nuxt</div>
    </GoopCollapsibleContent>
  </GoopCollapsible>
</template>
```

#react
```tsx
'use client'
import { useState } from 'react'
import { GoopButton, GoopCollapsible, GoopCollapsibleContent, GoopCollapsibleTrigger } from '@goopui/react'

export function Starred() {
  const [open, setOpen] = useState(false)
  return (
    <GoopCollapsible open={open} onOpenChange={setOpen} className="flex flex-col gap-2">
      <div className="flex items-center justify-between">
        <span>3 starred repositories</span>
        <GoopCollapsibleTrigger asChild>
          <GoopButton variant="outline" size="sm">{open ? 'Hide' : 'Show'}</GoopButton>
        </GoopCollapsibleTrigger>
      </div>
      <div>goopui/core</div>
      <GoopCollapsibleContent className="flex flex-col gap-2">
        <div>goopui/react</div>
        <div>goopui/nuxt</div>
      </GoopCollapsibleContent>
    </GoopCollapsible>
  )
}
```
::

The parts are `GoopCollapsible`, `GoopCollapsibleTrigger`, and `GoopCollapsibleContent`. Like shadcn, the trigger and content are unstyled.

## Driving it from code

::fw
#vue
`GoopAccordionItem` and `GoopCollapsible` expose their engine handle as `handle` (`null` before they mount, or when `goo` is off).

#react
On `GoopAccordionItem` and `GoopCollapsible`, `ref` is the element and `goopRef` receives the live `AccordionHandle` (`null` before they mount, or when `goo` is off).

## Accessibility

::fw
#vue
Keyboard navigation, focus handling, and ARIA attributes (`aria-expanded`, `aria-controls`, the region roles) come from reka-ui. The goo layer is `aria-hidden` and can't be clicked, and the text is never filtered. Under reduced motion, the open row is a still fill with no flood, wobble, or droplets, and the content opens with a plain height animation. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Keyboard navigation, focus handling, and ARIA attributes (`aria-expanded`, `aria-controls`, the region roles) come from Radix. The goo layer is `aria-hidden` and can't be clicked, and the text is never filtered. Under reduced motion, the open row is a still fill with no flood, wobble, or droplets, and the content opens with a plain height animation. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
