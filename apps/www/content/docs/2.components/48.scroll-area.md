#vue
`GoopScrollArea` and `GoopScrollBar` are shadcn-vue's Scroll Area parts on reka-ui's [`ScrollArea`](https://reka-ui.com/docs/components/scroll-area), with the same markup and classes. Swap the imports and you're done.

#react
`GoopScrollArea` and `GoopScrollBar` are shadcn/ui's Scroll Area parts on [Radix ScrollArea](https://www.radix-ui.com/primitives/docs/components/scroll-area), with the same markup and classes. Swap the imports and you're done. Both are client components, like shadcn's.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopScrollArea` and `GoopScrollBar`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopScrollArea` and `GoopScrollBar` from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopScrollArea, GoopSeparator } from '@goopui/vue'

const tags = Array.from({ length: 50 }, (_, i) => `v1.2.0-beta.${50 - i}`)
</script>

<template>
  <GoopScrollArea class="h-72 w-48 rounded-md border">
    <div class="p-4">
      <h4 class="mb-4 text-sm leading-none font-medium">Tags</h4>
      <template v-for="tag in tags" :key="tag">
        <div class="text-sm">{{ tag }}</div>
        <GoopSeparator class="my-2" />
      </template>
    </div>
  </GoopScrollArea>
</template>
```

#react
```tsx
import { GoopScrollArea, GoopSeparator } from '@goopui/react'
import { Fragment } from 'react'

const tags = Array.from({ length: 50 }, (_, i) => `v1.2.0-beta.${50 - i}`)

export function Tags() {
  return (
    <GoopScrollArea className="h-72 w-48 rounded-md border">
      <div className="p-4">
        <h4 className="mb-4 text-sm leading-none font-medium">Tags</h4>
        {tags.map((tag) => (
          <Fragment key={tag}>
            <div className="text-sm">{tag}</div>
            <GoopSeparator className="my-2" />
          </Fragment>
        ))}
      </div>
    </GoopScrollArea>
  )
}
```

## What it does

- **stretch.** While the content scrolls, the thumb stretches a little with the speed: a short tail trails behind its leading end and it thins a touch across, like a drop pulled along. When the scrolling stops it springs back.
- **jelly.** Keep pushing past an end (mouse wheel, trackpad or a finger) and the thumb squashes against that end; let go and it springs back with a small jelly wobble. A fast scroll that runs into an end gives it a little bump too.
- **Never clipped, never in the way.** The goo is a transform on the thumb's own body: no layout shift, the scroll size never changes, and the stretch is limited to the room left in the track. Scrolling itself is untouched (passive listeners only).
- **Cheap.** Nothing runs at rest; a spring runs for a moment after each scroll.
- **Reduced motion.** A plain, still thumb.
- **Server render.** SSR renders shadcn's markup; the goo starts in the browser.

## Props

::component-props{name="scroll-area"}
::

::fw
#vue
`GoopScrollArea` also takes reka's `type`, `dir` and `scrollHideDelay`, and exposes `handle` (the live `ScrollAreaHandle`, `null` before mount or with the goo off) and `el`. `GoopScrollBar` takes `orientation` and `class`; its thumb follows its `GoopScrollArea`.

#react
`GoopScrollArea` also takes Radix's `type`, `dir` and `scrollHideDelay`; its `ref` is the root element and `goopRef` receives the live `ScrollAreaHandle` (`null` before mount or with the goo off). `GoopScrollBar` takes `orientation` and `className`; its thumb follows its `GoopScrollArea`.
::

## Accessibility

Same markup and keyboard behaviour as shadcn. The thumb's goo body is `aria-hidden` and still under reduced motion. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
