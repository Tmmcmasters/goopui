#vue
`GoopRangeCalendar` and its parts (`GoopRangeCalendarHeader`, `GoopRangeCalendarHeading`, `GoopRangeCalendarPrevButton`, `GoopRangeCalendarNextButton`, `GoopRangeCalendarGrid`, `GoopRangeCalendarGridHead`, `GoopRangeCalendarGridBody`, `GoopRangeCalendarGridRow`, `GoopRangeCalendarHeadCell`, `GoopRangeCalendarCell`, `GoopRangeCalendarCellTrigger`) are shadcn-vue's Range Calendar on reka-ui's RangeCalendar, with the same markup, classes and props. Swap the imports and you're done.

#react
shadcn/ui's range calendar is its Calendar with `mode="range"`; `GoopRangeCalendar` is exactly that (`<GoopCalendar mode="range">`), named like the Vue one. It takes [GoopCalendar](/docs/components/calendar)'s props with `selected` / `onSelect` as a `DateRange` (`{ from, to }`). It is a client component.

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports GoopRangeCalendar. In plain Vue, import it:
import { GoopRangeCalendar } from '@goopui/vue'
import { getLocalTimeZone, today } from '@internationalized/date'
import type { DateRange } from 'reka-ui'
import { shallowRef } from 'vue'

const start = today(getLocalTimeZone())
const range = shallowRef<DateRange>({ start, end: start.add({ days: 6 }) })
</script>

<template>
  <GoopRangeCalendar v-model="range" class="rounded-lg border" />
</template>
```

#react
```tsx
import { GoopRangeCalendar, type DateRange } from '@goopui/react'
import { useState } from 'react'

export function TripDates() {
  const [range, setRange] = useState<DateRange | undefined>(() => {
    const from = new Date()
    return { from, to: new Date(from.getFullYear(), from.getMonth(), from.getDate() + 6) }
  })
  return <GoopRangeCalendar selected={range} onSelect={setRange} className="rounded-lg border" />
}
```

As in react-day-picker, the first click starts a one-day range and the next one sets its end.
::

## What it does

- **band.** The days of the range fill as one gooey body. Neighbouring days in a week merge, each week ends in a soft round end and the band carries on at the start of the next row. While you pick the end, the hover preview is the same band. Extending the range grows it out day by day from the band; shrinking it drains the far end first.
- **The caps.** The start and end days are primary goo that floods in, with a small `pulse` as it lands, and their labels follow the goo's edge.
- **slosh** and **focus** work as on the [Calendar](/docs/components/calendar#what-it-does): the month sloshes as you page, and the hover / keyboard-focus wash glides from day to day.
- **Reduced motion.** Static band and caps, the wash snaps, no slosh.

::fw
#vue
`GoopRangeCalendar` exposes `handle` (the live `CalendarHandle`) and `el` (the root). Every part takes `class`. Theme the goo with `--goop-calendar-range` (the band, default `--accent`), `--goop-calendar-selected` (the caps, default `--primary`) and `--goop-calendar-text` (the caps' labels, default `--primary-foreground`).

#react
`GoopRangeCalendar`'s `ref` is the root and `goopRef` receives the live `CalendarHandle`. Theme the goo with `--goop-calendar-range` (the band, default `--muted` like shadcn/ui React's range; set it on the calendar), `--goop-calendar-selected` (the caps, default `--primary`) and `--goop-calendar-text` (the caps' labels, default `--primary-foreground`).
::

## Accessibility

::fw
#vue
Same markup and keyboard as reka-ui's RangeCalendar. The goo layers and the label copies on them are `aria-hidden`. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Same markup and keyboard as react-day-picker's range mode. The goo layers and the label copies on them are `aria-hidden`. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
