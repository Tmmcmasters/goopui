#vue
`GoopCombobox` wraps the same [reka-ui Combobox](https://reka-ui.com/docs/components/combobox) primitive as shadcn-vue's Combobox, with the same API: filtering, keyboard navigation, `by`, `multiple`, and form submission work the same. Swap the imports and you're done. Install it like [Command](/docs/components/command).

#react
`GoopCombobox` is shadcn/ui's combobox recipe, [cmdk](https://cmdk.paco.me) inside a Radix Popover, shipped as parts with the same shape as the Vue `GoopCombobox`: an input with a chevron, and a list that opens below it. Typing opens the list and filters it with cmdk's filter; the chevron opens it unfiltered, with the chosen item highlighted. Values are strings (cmdk's item values); `multiple` makes the value a string array. Install it like [Command](/docs/components/command).
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
const frameworks = [
  { value: 'nuxt', label: 'Nuxt' },
  { value: 'sveltekit', label: 'SvelteKit' },
  { value: 'astro', label: 'Astro' },
]
const framework = ref()
</script>

<template>
  <GoopCombobox v-model="framework" by="value">
    <GoopComboboxAnchor class="relative w-56">
      <GoopComboboxInput class="pr-8" placeholder="Select framework..." :display-value="(v) => v?.label ?? ''" />
      <GoopComboboxTrigger class="absolute inset-y-0 right-0" aria-label="Show frameworks" />
    </GoopComboboxAnchor>
    <GoopComboboxList class="w-(--reka-combobox-trigger-width)">
      <GoopComboboxEmpty>No framework found.</GoopComboboxEmpty>
      <GoopComboboxGroup>
        <GoopComboboxItem v-for="f in frameworks" :key="f.value" :value="f">
          {{ f.label }}
          <GoopComboboxItemIndicator />
        </GoopComboboxItem>
      </GoopComboboxGroup>
    </GoopComboboxList>
  </GoopCombobox>
</template>
```

#react
```tsx
'use client'
import {
  GoopCombobox,
  GoopComboboxAnchor,
  GoopComboboxEmpty,
  GoopComboboxGroup,
  GoopComboboxInput,
  GoopComboboxItem,
  GoopComboboxItemIndicator,
  GoopComboboxList,
  GoopComboboxTrigger,
} from '@goopui/react'
import { useState } from 'react'

const frameworks = [
  { value: 'nuxt', label: 'Nuxt' },
  { value: 'sveltekit', label: 'SvelteKit' },
  { value: 'astro', label: 'Astro' },
]
const label = (v: string) => frameworks.find((f) => f.value === v)?.label ?? ''

export function FrameworkPicker() {
  const [framework, setFramework] = useState('')
  return (
    <GoopCombobox value={framework} onValueChange={setFramework}>
      <GoopComboboxAnchor className="relative w-56">
        <GoopComboboxInput className="pr-8" placeholder="Select framework..." displayValue={label} />
        <GoopComboboxTrigger className="absolute inset-y-0 right-0" aria-label="Show frameworks" />
      </GoopComboboxAnchor>
      <GoopComboboxList className="w-(--radix-popover-trigger-width)">
        <GoopComboboxEmpty>No framework found.</GoopComboboxEmpty>
        <GoopComboboxGroup>
          {frameworks.map((f) => (
            <GoopComboboxItem key={f.value} value={f.value} keywords={[f.label]}>
              {f.label}
              <GoopComboboxItemIndicator />
            </GoopComboboxItem>
          ))}
        </GoopComboboxGroup>
      </GoopComboboxList>
    </GoopCombobox>
  )
}
```

cmdk filters on an item's `value`; `keywords` adds its label, so typing "Next.js" finds `next`.
::

The parts are `GoopCombobox`, `Anchor`, `Input`, `Trigger`, `Cancel`, `List`, `Empty`, `Group`, `Item`, `ItemIndicator`, and `Separator`, each prefixed with `GoopCombobox`. The list's goo lives on `GoopComboboxList`; the input's ring on `GoopComboboxInput`.

## Behavior

- **Bloom.** The list pools from its own center, spreads with a lobed edge, overshoots, and splashes all around, kept off the input. Close pulls it in and shrinks it back (`openSlosh`, `openDrips`, `closeSlosh`).
- **Highlight.** The active item's background is a goo blob that glides between items with the keys and the pointer (`highlight`, `momentum`, `wobble`, `followPointer`). When typing hides the highlighted item, the blob shrinks out.
- **Choose.** Picking an item squishes the blob (`pop`), sets the value at once, and closes the list once the pop has played. Its check mark plops in (`plop`).
- **Input ring.** `GoopComboboxInput` gets GoopInput's goo focus ring (`goo` off on it turns the ring off).

## Turning parts off

::fw
#vue
```vue
<GoopComboboxList :plop="false">...</GoopComboboxList>        <!-- the check mark just appears -->
<GoopComboboxList :highlight="false">...</GoopComboboxList>   <!-- shadcn's flat highlight -->
<GoopComboboxList :open-drips="false">...</GoopComboboxList>  <!-- no splash -->
<GoopComboboxInput :goo="false" />                            <!-- no ring -->
<GoopComboboxList :goo="false">...</GoopComboboxList>         <!-- plain shadcn list -->
```

#react
```tsx
<GoopComboboxList plop={false}>...</GoopComboboxList>        {/* the check mark just appears */}
<GoopComboboxList highlight={false}>...</GoopComboboxList>   {/* shadcn's flat highlight */}
<GoopComboboxList openDrips={false}>...</GoopComboboxList>   {/* no splash */}
<GoopComboboxInput goo={false} />                            {/* no ring */}
<GoopComboboxList goo={false}>...</GoopComboboxList>         {/* plain shadcn list */}
```

## Props

::fw
#vue
`GoopComboboxList` takes reka-ui's `ComboboxContent` props (defaults `position="popper"`, `align="start"`, `sideOffset` 4), `class`, and the same goo props as [GoopSelectContent](/docs/components/select#props) except `bloomFrom`: a combobox list always blooms from its own center. `GoopComboboxInput` takes reka-ui's `ComboboxInput` props, GoopInput's ring props, and `goo`. The other parts take shadcn-vue's props.

#react
`GoopCombobox` takes `value` / `defaultValue` / `onValueChange`, `multiple`, `open` / `defaultOpen` / `onOpenChange`, `ignoreFilter`, `disabled`, and cmdk's `Command` props (`filter`, `loop`, ...). `GoopComboboxList` takes Radix's `Popover.Content` props (defaults `side="bottom"`, `align="start"`, `sideOffset` 6), `className`, `goopRef` / `highlightRef`, and the same goo props as GoopSelectContent except `bloomFrom`: a combobox list always blooms from its own center. `GoopComboboxInput` takes cmdk's input props, `displayValue`, `onSearchChange`, GoopInput's ring props, and `goo`. `GoopComboboxItem` takes cmdk's item props with a required `value`.

## Accessibility

::fw
#vue
The combobox and listbox roles, `aria-activedescendant`, keyboard navigation, and focus handling come from reka-ui. The goo surface, highlight blob, and ring are `aria-hidden` and can't be clicked. Under reduced motion the list opens and closes plainly, the highlight snaps, there's no pop or plop, and the ring is static. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
The combobox and listbox roles, `aria-activedescendant` and keyboard navigation come from cmdk; Escape and clicks outside close the list (Radix Popover), and focus stays in the input. The goo surface, highlight blob, and ring are `aria-hidden` and can't be clicked. Under reduced motion the list opens and closes plainly, the highlight snaps, there's no pop or plop, and the ring is static. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
