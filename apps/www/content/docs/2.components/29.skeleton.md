## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopSkeleton`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopSkeleton` (and `GoopSkeletonReveal`) from `@goopui/react`.

## What it does

- **shimmer.** A low, wide mound of slightly lighter goo rises from the bottom edge of the shape and drifts across it, swelling a little as it crosses the middle, then rests off-shape for a moment before the next pass.

It's built to be cheap. The mound is one CSS gradient moved with a transform, so no script runs per frame and nothing is filtered. A page with hundreds of skeletons stays smooth.

::fw
#vue
The crest is `--goop-shimmer-color` at `--goop-shimmer-base` opacity: white at `0.85` on a light theme (the accent is pale) and the theme's `--foreground` at `0.16` under `.dark`. Tune either with a class, e.g. `class="dark:[--goop-shimmer-base:0.1]"`.

#react
The crest is `--goop-shimmer-color` at `--goop-shimmer-base` opacity: white at `0.85` on a light theme (the muted fill is pale) and the theme's `--foreground` at `0.16` under `.dark`. Tune either with a class, e.g. `className="dark:[--goop-shimmer-base:0.1]"`.

## Reveal: melt into the content

::fw
#vue
`GoopSkeletonReveal` is a goopUI addition; shadcn has no equivalent. Put the skeleton in its `#skeleton` slot and the real content in the default slot, and flip `loading` when the data arrives.

#react
`GoopSkeletonReveal` is a goopUI addition; shadcn has no equivalent. Pass the skeleton as its `skeleton` prop and the real content as `children`, and flip `loading` when the data arrives.
::

While it loads, the group's blocks pool into one soft body of goo: a slow sheen flows through them and close neighbours bridge with goo as it passes, and each block breathes a little. When `loading` turns `false`, each block flows into the element that replaces it (the circle into the avatar, the bars into the text's lines, the block into the button, taking its colour), with a small stagger from the top, then drains away to reveal the crisp content.

::playground{name="skeleton-reveal" caption="A profile card loading. Press Reload to watch it again."}
:demo-skeleton-reveal
::

::fw
#vue
```vue
<script setup lang="ts">
const loading = ref(true)
const user = ref<User | null>(null)
onMounted(async () => {
  user.value = await fetchUser()
  loading.value = false
})
</script>

<template>
  <GoopCard class="w-full max-w-sm">
    <GoopSkeletonReveal :loading="loading" class="grid gap-4 px-6">
      <template #skeleton>
        <!-- GoopSkeleton blocks, laid out like the content -->
      </template>
      <!-- the content (rendered once loading is false) -->
    </GoopSkeletonReveal>
  </GoopCard>
</template>
```

#react
```tsx
'use client'
import { GoopCard, GoopSkeleton, GoopSkeletonReveal } from '@goopui/react'
import { useEffect, useState } from 'react'

export function Profile() {
  const [user, setUser] = useState<User | null>(null)
  useEffect(() => {
    fetchUser().then(setUser)
  }, [])

  return (
    <GoopCard className="w-full max-w-sm">
      <GoopSkeletonReveal
        loading={!user}
        className="grid gap-4 px-(--card-spacing)"
        skeleton={<>{/* GoopSkeleton blocks, laid out like the content */}</>}
      >
        {/* the content (rendered once loading is false) */}
      </GoopSkeletonReveal>
    </GoopCard>
  )
}
```
::

It works with any content, not only cards. Blocks are paired with what replaces them by overlap: images, avatars, buttons, inputs, badges and anything marked `data-goop-reveal` count as one shape; other text melts into its line boxes. A block with nothing under it drains in place.

::fw
#vue
Give the skeleton the content's exact layout (same rows, same heights: wrap a bar in a row as tall as the text's line), so nothing moves when it swaps. Both slots render into the root, so its `class` lays out either. Keep the card frame outside the reveal, as above, so only its inside changes.

#react
Give the skeleton the content's exact layout (same rows, same heights: wrap a bar in a row as tall as the text's line), so nothing moves when it swaps. Both render into the root, so its `className` lays out either. Keep the card frame outside the reveal, as above, so only its inside changes. `onRevealed` fires when the melt is done, and `goopRef` receives the engine handle.

## Accessibility

A skeleton is decoration. Pair it with an `aria-busy="true"` region or a visually hidden "Loading" message, as you would with shadcn's. `GoopSkeletonReveal` sets `aria-busy="true"` on its root while `loading`, and its goo layer is `aria-hidden`.

Under reduced motion the shimmer stops and the skeleton is a plain, static shape. `GoopSkeletonReveal` then shows still blocks (no pooled goo) and cross-fades to the content. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
