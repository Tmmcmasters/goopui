::fw
#vue
`GoopDrawer` has the API of shadcn-vue's Drawer, which is built on [vaul-vue](https://github.com/unovue/vaul-vue). goopUI doesn't use vaul: it's a rebuild on reka-ui's Dialog (focus trapping, scroll locking, dismissal) with goopUI's own drag engine. The drag, snap points, springs, and goo all run in one frame, so the goo moves with the panel exactly. The root takes vaul's props, emits, and `v-model`s, so you can swap the imports and keep your code.

#react
`GoopDrawer` has the API of shadcn/ui's Drawer, which is built on [vaul](https://github.com/emilkowalski/vaul). goopUI doesn't use vaul: it's a rebuild on [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) (focus trapping, scroll locking, dismissal) with goopUI's own drag engine, the same one the Vue drawer runs. The drag, snap points, springs, and goo all run in one frame, so the goo moves with the panel exactly. The root takes vaul's props and callbacks, and the parts take shadcn/ui's classes, so you can swap the imports and keep your code.
::

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopDrawer*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--background`, `--muted`, `--foreground`). You don't install `vaul-vue`.

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). It needs Tailwind CSS v4 and the shadcn tokens (`--popover`, `--popover-foreground`, `--muted`, `--muted-foreground`). You don't install `vaul`.

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {

  GoopDrawer,
  GoopDrawerClose,

  GoopDrawerDescription,
  GoopDrawerFooter,

  GoopDrawerTrigger,

<template>
  <GoopDrawer>

      <GoopDrawerHeader>
        <GoopDrawerTitle>Move goal</GoopDrawerTitle>

```

::

The parts are `GoopDrawer`, `GoopDrawerTrigger`, `GoopDrawerContent`, `GoopDrawerHeader`, `GoopDrawerFooter`, `GoopDrawerTitle`, `GoopDrawerDescription`, `GoopDrawerClose`, `GoopDrawerOverlay`, and `GoopDrawerPortal`. The vaul props go on `GoopDrawer`. All the goo lives on `GoopDrawerContent`, which also renders the overlay and, on bottom drawers, the drag handle.

## Behavior

- **Drag.** The panel follows your finger, with a rubber band past full open. Release, and it snaps open, to a snap point, or closed, with vaul's thresholds. Opens and snaps travel fast and land with a small overshoot. Closes fall away.
- **Lag.** The leading edge trails behind fast motion. A quick pull stretches it out behind the panel (`lag`).
- **Slosh and rise.** When the panel stops (release, a snap point, landing), the edge overshoots and wobbles (`slosh`). Opening adds an extra jelly overshoot as it lands (`rise`).
- **Stretch.** Dragging past full open pulls a globby bump toward your finger (`stretch`).
- **Handle.** The drag handle is a goo blob. It swells when you grab it, stretches along the drag, and trails a droplet (`handle`).
- **Splash.** Fling it away and a splash of drops tears off the leading edge, flies, falls, and fades (`splash`).
- **Content stays sharp.** Only the panel's background is goo, drawn on an `aria-hidden` surface behind your content. Like the sheet, it draws with the canvas renderer by default.

## Snap points

::fw
#vue
`snapPoints` takes viewport fractions (0 to 1) or px strings (`'300px'`), least visible first. Bind the current one with `v-model:active-snap-point`. The edge sloshes every time it lands on one. `fadeFromIndex` sets the snap point from which the overlay is fully shown.

#react
`snapPoints` takes viewport fractions (0 to 1) or px strings (`'300px'`), least visible first. Control the current one with `activeSnapPoint` and `setActiveSnapPoint`, as in vaul. The edge sloshes every time it lands on one. `fadeFromIndex` sets the snap point from which the overlay is fully shown.
::

::preview{:controls="false"}
:demo-drawer{set="snap"}
::

::fw
#vue
```vue
<script setup lang="ts">
const snapPoints = [0.35, 0.65, 1]
const snap = ref<number | string | null>(snapPoints[0])
</script>

<template>
  <GoopDrawer v-model:active-snap-point="snap" :snap-points="snapPoints">
    <GoopDrawerTrigger as-child>
      <GoopButton variant="outline">Snap points</GoopButton>
    </GoopDrawerTrigger>
    <GoopDrawerContent class="h-full max-h-[97%]">...</GoopDrawerContent>
  </GoopDrawer>
</template>
```

#react
```tsx
const snapPoints = [0.35, 0.65, 1]

export function Snapping() {
  const [snap, setSnap] = useState<number | string | null>(snapPoints[0])
  return (
    <GoopDrawer snapPoints={snapPoints} activeSnapPoint={snap} setActiveSnapPoint={setSnap}>
      <GoopDrawerTrigger asChild>
        <GoopButton variant="outline">Snap points</GoopButton>
      </GoopDrawerTrigger>
      <GoopDrawerContent className="h-full max-h-[97%]">...</GoopDrawerContent>
    </GoopDrawer>
  )
}
```

## Background scale

Like vaul, an open drawer scales the page behind it back, with rounded corners, and paints `<body>` black behind it. Mark the element that wraps your page:

::fw
#vue
```vue [app.vue]
<template>
  <div data-vaul-drawer-wrapper class="min-h-dvh bg-background">
    <NuxtPage />
  </div>
</template>
```

#react
```tsx [app/layout.tsx]
<body>
  <div data-vaul-drawer-wrapper="" className="min-h-dvh bg-background">
    {children}
  </div>
</body>
```
::

The engine looks for `[data-vaul-drawer-wrapper]` first, then `[data-goop-drawer-wrapper]`, so an app already set up for vaul works as it is. The scale follows the drag every frame, and the wrapper's own styles are put back when the drawer closes. Without a wrapper nothing is scaled.

::fw
#vue
Turn it off with `:should-scale-background="false"`, or keep the scale but skip the black body with `:set-background-color-on-scale="false"` (or `no-body-styles`). This site has no wrapper, so the demos above don't scale it.

#react
Turn it off with `shouldScaleBackground={false}`, or keep the scale but skip the black body with `setBackgroundColorOnScale={false}` (or `noBodyStyles`). This site has no wrapper, so the demos above don't scale it.
::

## Nested drawers

Open a `GoopDrawer` with `nested` inside another one and the parent recedes while the child is open, following the child as you drag it.

## Events

::fw
#vue
`GoopDrawer` emits vaul's events: `update:open`, `update:activeSnapPoint`, `drag` (the share of the panel dragged), `release` (whether it stays open), `close` (it started closing), and `animationEnd` (an open or close finished).

#react
`GoopDrawer` takes vaul's callbacks: `onOpenChange`, `setActiveSnapPoint`, `onDrag` (the share of the panel dragged), `onRelease` (whether it stays open), `onClose` (it started closing), and `onAnimationEnd` (an open or close finished). vaul passes the pointer event as the first argument of `onDrag` and `onRelease`; goopUI's engine tracks the pointer itself, so that argument is `null`.
::

## Driving it from code

::fw
#vue
`GoopDrawerContent` exposes the live drawer controller as `handle` (`null` while closed). Open and close it with `v-model:open` on `GoopDrawer`.

#react
`goopRef` on `GoopDrawerContent` gets the live drawer controller (`null` while closed); `ref` is the panel element, as in shadcn. Open and close it with `open` and `onOpenChange` on `GoopDrawer`.
::

## Accessibility

::fw
#vue
Focus trapping, scroll locking, Escape and outside-click dismissal, and ARIA attributes come from reka-ui. With `dismissible` off, Escape and outside clicks don't close it, so give it a close button. The goo surface and the handle are `aria-hidden`. Under reduced motion you can still drag it and it still snaps, but there's no goo motion: no lag, slosh, rise, stretch, or splash, and snaps land without the wobble. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Focus trapping, scroll locking, Escape and outside-click dismissal, and ARIA attributes come from Radix. With `dismissible` off, Escape and outside clicks don't close it, so give it a close button. The goo surface and the handle are `aria-hidden`. Under reduced motion you can still drag it and it still snaps, but there's no goo motion: no lag, slosh, rise, stretch, or splash, and snaps land without the wobble. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
