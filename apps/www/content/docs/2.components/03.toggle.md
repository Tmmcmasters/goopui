::fw
#vue
`GoopToggle` wraps reka-ui's [`Toggle`](https://reka-ui.com/docs/components/toggle), the same primitive as shadcn-vue's Toggle, with the same API, variants, sizes, and classes. `v-model`, `disabled`, `asChild`, keyboard handling, and `aria-pressed` all come from reka-ui. The pressed background is goo, drawn on a layer inside the button.

#react
`GoopToggle` wraps Radix's [`Toggle`](https://www.radix-ui.com/primitives/docs/components/toggle), the same primitive as shadcn/ui's Toggle, with the same API, variants, sizes, and classes. `pressed`, `defaultPressed`, `onPressedChange`, `disabled`, `asChild`, keyboard handling, and `aria-pressed` all come from Radix. The pressed background is goo, drawn on a layer inside the button.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopToggle`, `GoopToggleGroup`, and `GoopToggleGroupItem`. The goo fill uses shadcn's pressed-toggle token, `--accent`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopToggle`, `GoopToggleGroup`, and `GoopToggleGroupItem` from `@goopui/react`. The goo fill uses shadcn's pressed-toggle token, `--accent`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports this. In plain Vue, import it:
import { GoopToggle } from '@goopui/vue'

const bold = ref(false)
</script>

<template>
  <GoopToggle v-model="bold" aria-label="Toggle bold">
    <span class="font-bold">B</span> Bold
  </GoopToggle>
</template>
```

#react
```tsx
import { GoopToggle } from '@goopui/react'
import { useState } from 'react'

export function BoldToggle() {
  const [bold, setBold] = useState(false)
  return (
    <GoopToggle pressed={bold} onPressedChange={setBold} aria-label="Toggle bold">
      <span className="font-bold">B</span> Bold
    </GoopToggle>
  )
}
```
::

## What it does

- **flood.** Pressing floods the button with goo from the press point (its center for keyboard presses). Un-pressing drains it back into that point.
- **wobble.** The flood front has a crest that sloshes against the walls, and the full fill does a small jelly wobble.
- **droplets.** A few droplets splash off the top edge as the front reaches it.

::fw
#vue
`aria-pressed` and `data-state` flip on click, as in any reka-ui toggle. Only the fill animates.

#react
`aria-pressed` and `data-state` flip on click, as in any Radix toggle. Only the fill animates.
::

## Toggle group

::fw
#vue
`GoopToggleGroup` and `GoopToggleGroupItem` wrap reka-ui's [`ToggleGroupRoot`](https://reka-ui.com/docs/components/toggle-group) and `ToggleGroupItem`, like shadcn-vue's ToggleGroup. All the pressed fills are one goo layer on the group, which adds two effects:

#react
`GoopToggleGroup` and `GoopToggleGroupItem` wrap Radix's [`ToggleGroup`](https://www.radix-ui.com/primitives/docs/components/toggle-group) Root and Item, like shadcn/ui's ToggleGroup. `type` (`'single'` or `'multiple'`) is required. `value`, `defaultValue`, and `onValueChange` take a string in a single group and a string array in a multiple group. All the pressed fills are one goo layer on the group, which adds two effects:
::

- **flow.** In a `type="single"` group, the goo leaves the old item: it gathers into a blob, stretches out on a neck, pinches off, travels over the items in between, and floods the new item from the side it arrived on.
- **merge.** Neighbouring pressed items join through goo bridges across their seam, so a run of pressed items reads as one body. Un-press one and it drains while the bridges neck and tear.

::preview{caption="Pick an alignment. The goo travels between items." :controls="false"}
:demo-toggle{set="single"}
::

::fw
#vue
```vue
<script setup lang="ts">
import { GoopToggleGroup, GoopToggleGroupItem } from '@goopui/vue'

const align = ref('left')
</script>

<template>
  <GoopToggleGroup v-model="align" type="single" variant="outline" aria-label="Text alignment">
    <GoopToggleGroupItem value="left">Left</GoopToggleGroupItem>
    <GoopToggleGroupItem value="center">Center</GoopToggleGroupItem>
    <GoopToggleGroupItem value="right">Right</GoopToggleGroupItem>
    <GoopToggleGroupItem value="justify">Justify</GoopToggleGroupItem>
  </GoopToggleGroup>
</template>
```

#react
```tsx
import { GoopToggleGroup, GoopToggleGroupItem } from '@goopui/react'
import { useState } from 'react'

export function Alignment() {
  const [align, setAlign] = useState('left')
  return (
    <GoopToggleGroup
      type="single"
      value={align}
      onValueChange={setAlign}
      variant="outline"
      aria-label="Text alignment"
    >
      <GoopToggleGroupItem value="left">Left</GoopToggleGroupItem>
      <GoopToggleGroupItem value="center">Center</GoopToggleGroupItem>
      <GoopToggleGroupItem value="right">Right</GoopToggleGroupItem>
      <GoopToggleGroupItem value="justify">Justify</GoopToggleGroupItem>
    </GoopToggleGroup>
  )
}
```

## Colors

The goo reads `--goop-toggle-fill`, which defaults to `var(--accent)`, the color shadcn fills a pressed toggle with. Override it on the toggle, the group, or an ancestor:

::fw



## Props

### GoopToggle

::fw
#vue
Keeps the shadcn-vue Toggle API and adds the goo props.

#react
Keeps the shadcn/ui Toggle API and adds the goo props.
::

::component-props{name="toggle"}
::

::fw
#vue
The default slot receives reka-ui's slot props. `GoopToggle` also exposes `handle` (the live toggle handle, `null` before mount or with `goo` off) and `el` (the button).

#react
`ref` is the button, as in shadcn/ui. `goopRef` receives the live toggle handle (`null` before mount or with `goo` off).
::

### GoopToggleGroup

::fw
#vue
Keeps the shadcn-vue ToggleGroup API and adds the goo props, including `flow` and `merge`.

#react
Keeps the shadcn/ui ToggleGroup API and adds the goo props, including `flow` and `merge`. `orientation` defaults to `'horizontal'`, and `rovingFocus`, `loop`, `dir`, and `disabled` pass through to Radix.
::

::component-props{name="toggle" part="group"}
::

::fw
#vue
It exposes `handle` and `el` (the root, `role="group"`).

#react
`ref` is the root, and `goopRef` receives the live toggle handle.
::

### GoopToggleGroupItem

::fw
#vue
Keeps the shadcn-vue ToggleGroupItem API: `value` (required), `disabled`, `variant`, `size`, `asChild`, `as`, and `class`. It has no goo props of its own. `variant` and `size` come from the group when the group sets them. Inside an active `GoopToggleGroup`, a pressed item drops its own background, because the group's goo is the fill.

Before they mount, during SSR, and with `:goo="false"`, they are plain shadcn toggles, so first paint and hydration match.

#react
Keeps the shadcn/ui ToggleGroupItem API: `value` (required), `disabled`, `variant`, `size`, `asChild`, and `className`. It has no goo props of its own. `variant` and `size` come from the group when the group sets them. Inside an active `GoopToggleGroup`, a pressed item drops its own background, because the group's goo is the fill.

On the server, before they mount, and with `goo={false}`, they are plain shadcn toggles, so first paint and hydration match.
::

## Accessibility

::fw
#vue
They're real reka-ui toggles: buttons with `aria-pressed`, a focus ring, and Space or Enter to press. A group uses roving focus with arrow keys. The goo layers are `aria-hidden` and can't be clicked, and labels and icons are never filtered.

#react
They're real Radix toggles: buttons with a focus ring, and Space or Enter to press. A `GoopToggle` has `aria-pressed`. A `type="single"` group is `role="radiogroup"` with `role="radio"` items and `aria-checked`, and a `type="multiple"` group is `role="toolbar"` with `aria-pressed` items. A group uses roving focus with arrow keys. The goo layers are `aria-hidden` and can't be clicked, and labels and icons are never filtered.
::

Under reduced motion the goo keeps its shape and the animation stops: pressed items are full and unpressed ones empty, merged neighbours stay merged, and nothing floods, drains, splashes, or travels. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
