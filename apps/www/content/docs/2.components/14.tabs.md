#vue
`GoopTabs` wraps the same [reka-ui Tabs](https://reka-ui.com/docs/components/tabs) primitive as shadcn-vue's Tabs, with the same API. Keyboard navigation and ARIA work the same. Swap the imports and you're done.

#react
`GoopTabs` wraps the same [Radix Tabs](https://www.radix-ui.com/primitives/docs/components/tabs) primitive as shadcn/ui's Tabs, with the same API. Keyboard navigation and ARIA work the same. Swap the imports and you're done.
::

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopTabs*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--muted`, `--background`, `--foreground`, `--input`, `--ring`, `--radius`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). It needs Tailwind CSS v4 and the shadcn tokens (`--muted`, `--background`, `--foreground`, `--input`, `--ring`, `--radius`).
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopTabs, GoopTabsContent, GoopTabsList, GoopTabsTrigger } from '@goopui/vue'
</script>

<template>
  <GoopTabs default-value="account">
    <GoopTabsList>
      <GoopTabsTrigger value="account">Account</GoopTabsTrigger>
      <GoopTabsTrigger value="password">Password</GoopTabsTrigger>
    </GoopTabsList>
    <GoopTabsContent value="account">Make changes to your account here.</GoopTabsContent>
    <GoopTabsContent value="password">Change your password here.</GoopTabsContent>
  </GoopTabs>
</template>
```

#react
```tsx
import { GoopTabs, GoopTabsContent, GoopTabsList, GoopTabsTrigger } from '@goopui/react'

export function Settings() {
  return (
    <GoopTabs defaultValue="account">
      <GoopTabsList>
        <GoopTabsTrigger value="account">Account</GoopTabsTrigger>
        <GoopTabsTrigger value="password">Password</GoopTabsTrigger>
      </GoopTabsList>
      <GoopTabsContent value="account">Make changes to your account here.</GoopTabsContent>
      <GoopTabsContent value="password">Change your password here.</GoopTabsContent>
    </GoopTabs>
  )
}
```
::

All the goo lives on `GoopTabsList`. `GoopTabs`, `GoopTabsTrigger`, and `GoopTabsContent` are shadcn's.

## Behavior

- **The blob** is the active tab's background. It slides to the new trigger with momentum, stretching with a neck of lumps while it travels, and lands with a jelly overshoot (`momentum`, `wobble`).
- **It follows everything.** Clicks, the arrow keys, and programmatic changes. It tracks whichever trigger has `data-state="active"`.
- **Labels stay sharp.** The blob is `aria-hidden` and sits behind the real triggers. Text is never filtered.
- **Server render.** SSR renders shadcn's markup, and the active trigger is styled until the blob attaches in the browser.

## Tuning

Turn off the jelly or the stretch, change the feel, or go plain shadcn:

::preview{:controls="false"}
:demo-tabs{set="plain"}
::

::fw
#vue
```vue
<GoopTabsList preset="wild">...</GoopTabsList>
<GoopTabsList :wobble="false" :momentum="false">...</GoopTabsList>
<GoopTabsList :goo="false">...</GoopTabsList>
```

#react
```tsx
<GoopTabsList preset="wild">...</GoopTabsList>
<GoopTabsList wobble={false} momentum={false}>...</GoopTabsList>
<GoopTabsList goo={false}>...</GoopTabsList>
```
::

::fw
#vue
`:indicator="false"` keeps the list's goo setting but gives the active tab shadcn's flat background. `:goo="false"` renders exactly shadcn's TabsList and TabsTrigger.

#react
`indicator={false}` keeps the list's goo setting but gives the active tab shadcn's flat background. `goo={false}` renders exactly shadcn's TabsList and TabsTrigger.
::

## Driving it from code

::fw
#vue
`GoopTabsList` exposes `handle`, the live indicator handle (`null` before mount, when `goo` is off, or on the `line` variant).

#react
`GoopTabsList`'s `goopRef` receives the live indicator handle (`null` before mount, when `goo` is off, or on the `line` variant). `ref` is the list element, as in shadcn/ui.

## Accessibility

::fw
#vue
It's reka-ui's Tabs: a `tablist` with `tab` and `tabpanel` roles, roving focus, and arrow, Home, and End keys. Under reduced motion the blob snaps to the new tab with no stretch or overshoot, and still marks the active tab. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
It's Radix's Tabs: a `tablist` with `tab` and `tabpanel` roles, roving focus, and arrow, Home, and End keys. Under reduced motion the blob snaps to the new tab with no stretch or overshoot, and still marks the active tab. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
::
