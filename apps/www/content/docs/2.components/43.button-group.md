`GoopButtonGroup`, `GoopButtonGroupSeparator` and `GoopButtonGroupText` are shadcn-vue's ButtonGroup parts with the same markup, classes and `orientation`. Swap the imports and you're done.

## Installation

Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopButtonGroup*` part.

## Usage

```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopButton, GoopButtonGroup } from '@goopui/vue'
</script>

<template>
  <GoopButtonGroup>
    <GoopButton variant="outline">Archive</GoopButton>
    <GoopButton variant="outline">Report</GoopButton>
    <GoopButton variant="outline">Snooze</GoopButton>
  </GoopButtonGroup>
</template>
```

## What it does

- **press.** Press a button (pointer, Space or Enter) and it squishes: a little shorter across the group, a little longer along it. Let go and it springs back with a small jelly rebound.
- **tug.** Its neighbours are pulled toward it, as if the goo between them were shared: the near edge of each neighbour leans in a couple of pixels while its far edge stays put, and it shares some of the squish. The next one along gets less.
- **No gaps or seams.** Along the group every button only ever grows, so joined edges overlap and never open. It's all transforms, so nothing around the group moves.
- **Buttons inside stay shadcn.** A `GoopButton` inside a group leaves its own goo off (the group's joined corners and borders are shadcn's), unless you set `goo` on it. Plain buttons and links work too; text, separators and inputs flex with the group but never start a press.
- **Server render.** SSR renders shadcn's markup; the goo attaches in the browser.

## Orientation

::preview{:controls="false"}
:demo-button-group{set="vertical"}
::

```vue
<GoopButtonGroup orientation="vertical">
  <GoopButton variant="outline" size="icon"><PlusIcon /></GoopButton>
  <GoopButton variant="outline" size="icon"><MinusIcon /></GoopButton>
</GoopButtonGroup>
```

## Separator and text

::preview{:controls="false"}
:demo-button-group{set="separator"}
::

```vue
<GoopButtonGroup>
  <GoopButton variant="secondary">Copy</GoopButton>
  <GoopButtonGroupSeparator />
  <GoopButton variant="secondary">Paste</GoopButton>
</GoopButtonGroup>
<GoopButtonGroup>
  <GoopButtonGroupText>https://</GoopButtonGroupText>
  <GoopButton variant="outline">goop.dev</GoopButton>
</GoopButtonGroup>
```

## Props

::component-props{name="button-group"}
::

`GoopButtonGroupSeparator` takes reka-ui's Separator props (`orientation` defaults to vertical) and `class`. `GoopButtonGroupText` takes `as`, `asChild`, `orientation` and `class`. `GoopButtonGroup` exposes `handle` (`press(index)`, `release()`).

## Accessibility

It keeps shadcn's `role="group"`; label it with `aria-label` when the buttons need context. Under reduced motion nothing squishes. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
