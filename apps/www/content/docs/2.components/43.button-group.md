## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopButton, GoopButtonGroup } from '@goopui/vue'
</script>

<template>
  <GoopButtonGroup>
    <GoopButton variant="outline">Archive</GoopButton>
    <GoopButton variant="outline">Report</GoopButton>
    <GoopButton variant="outline">Snooze</GoopButton>
  </GoopButtonGroup>
</template>
```

#react
```tsx
import { GoopButton, GoopButtonGroup } from '@goopui/react'

export function MailActions() {
  return (
    <GoopButtonGroup>
      <GoopButton variant="outline">Archive</GoopButton>
      <GoopButton variant="outline">Report</GoopButton>
      <GoopButton variant="outline">Snooze</GoopButton>
    </GoopButtonGroup>
  )
}
```

## What it does

The whole group shares one goo layer, behind the buttons' real (unfiltered) labels and borders.

- **highlight.** The hover and keyboard-focus background is one goo blob that slides from button to button with a little momentum (`momentum`), lands with a soft jelly settle (`wobble`), and keeps a low, wide swell under the pointer (`followPointer`). It's ink, not green, so it reads on light and dark. On touch there's no sticky hover: the blob shows only while your finger is down. Outline and ghost buttons drop their own hover background while it's on; filled buttons (default, secondary) keep theirs and the blob passes behind them.
- **bulge.** Press a button (pointer, Space or Enter) and the goo under it swells a few pixels past its top and bottom edges: a low, wide mound, never a knob. Let go and it settles with a jelly rebound.
- **ripple.** The press sends two soft lumps of goo out of the button into its neighbours. They travel a little way and thin away.
- **press** and **tug.** The buttons flex with the goo: the pressed one squishes (a little shorter across the group, a little longer along it), and its neighbours lean in toward it, less the further away they are.
- **No gaps or seams.** Along the group every button only ever grows, so joined edges overlap and never open. The goo layer and the flex never change layout or scroll size, so nothing around the group moves.
- **Every effect is a prop.** Each one takes `false` to turn it off, or a number to scale it, and `preset` picks `subtle`, `playful` (the default) or `wild`. With `goo` off it's a plain shadcn ButtonGroup.
- **Buttons inside stay shadcn.** A `GoopButton` inside a group leaves its own goo off (the group's goo is the one body), unless you set `goo` on it. Plain buttons and links work too. Text, separators and inputs flex with the group but are never lit and never start a press.
- **Server render.** SSR renders shadcn's markup; the goo attaches in the browser.

## Props

::component-props{name="button-group"}
::

::fw
#vue
`GoopButtonGroupSeparator` takes reka-ui's Separator props (`orientation` defaults to vertical) and `class`. `GoopButtonGroupText` takes `as`, `asChild`, `orientation` and `class`. `GoopButtonGroup` exposes `handle` (`press(index)`, `release()`, `light(index)`).

#react
`GoopButtonGroupSeparator` takes Radix's Separator props (`orientation` defaults to vertical) and `className`. `GoopButtonGroupText` takes `asChild`, `className` and the `div` props. On `GoopButtonGroup`, `ref` is the group element and `goopRef` receives the live `ButtonGroupHandle` (`press(index)`, `release()`, `light(index)`; `null` before mount or with `goo` off).
::

## Accessibility

It keeps shadcn's `role="group"`; label it with `aria-label` when the buttons need context. The goo layer is `aria-hidden`; the blob follows keyboard focus as well as the pointer. Under reduced motion the highlight is static (it jumps to the button, no travel) and nothing bulges, ripples or squishes. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
