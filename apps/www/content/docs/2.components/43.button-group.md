## Installation

::fw

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the ButtonGroup parts from `@goopui/react`.

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopButton, GoopButtonGroup } from '@goopui/vue'
</script>

<template>
  <GoopButtonGroup>
    <GoopButton variant="outline">Archive</GoopButton>
    <GoopButton variant="outline">Report</GoopButton>
    <GoopButton variant="outline">Snooze</GoopButton>
  </GoopButtonGroup>
</template>
```

#react
```tsx
import { GoopButton, GoopButtonGroup } from '@goopui/react'

export function MailActions() {
  return (
    <GoopButtonGroup>
      <GoopButton variant="outline">Archive</GoopButton>
      <GoopButton variant="outline">Report</GoopButton>
      <GoopButton variant="outline">Snooze</GoopButton>
    </GoopButtonGroup>
  )
}
```

## What it does

- **Every segment is a GoopButton.** Each button keeps the same goo body it has on its own: it leans toward the pointer, moves with momentum, drips while you hover, and squishes and splashes when you press. Pressing a segment feels exactly like pressing a standalone button.
- **seams.** The group marks each button's joined edges and the goo is cut clean there: no bulge, drip or splash crosses onto a neighbour's label, and the body reaches under the seam so the strip never opens, even while it leans or squishes. Filled buttons fuse into one strip; outline buttons share a single 1px line at each seam, like shadcn's. Only the group's outer corners are rounded, and the goo follows each segment's real corners.
- **Outer edges stay gooey.** The top, bottom and two ends bulge, drip and splash as usual, and splash that flies out below or beside a seam stays whole. In a vertical group only the last button drips, so nothing hangs over the button below.
- **press and tug are opt-in.** The older whole-button squish (`press`) and neighbour pull (`tug`) are off by default, because each button's own goo already squishes. Turn them on for a group of plain buttons.
- **goo.** Set `goo` to false on the group and it renders a plain shadcn ButtonGroup with plain shadcn buttons. Set `goo` to false on a single button and only that button is plain.
- **Server render.** SSR renders shadcn's markup; the goo and the seam cuts attach in the browser, and nothing shifts layout.

## Props

::component-props{name="button-group"}
::

::fw
#vue
`GoopButtonGroupSeparator` takes reka-ui's Separator props (`orientation` defaults to vertical) and `class`. `GoopButtonGroupText` takes `as`, `asChild`, `orientation` and `class`. `GoopButtonGroup` exposes `handle` (`press(index)`, `release()`).

#react
`GoopButtonGroupSeparator` takes Radix's Separator props (`orientation` defaults to vertical) and `className`. `GoopButtonGroupText` takes `asChild`, `className` and the `div` props. On `GoopButtonGroup`, `ref` is the group element and `goopRef` receives the live `ButtonGroupHandle` (`press(index)`, `release()`; `null` before mount or with `goo` off).
::

## Accessibility

It keeps shadcn's `role="group"`; label it with `aria-label` when the buttons need context. A keyboard-focused button's focus ring shows in full over the seam. Under reduced motion each button's goo is a static body (still cut clean at the seams) and nothing squishes. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
