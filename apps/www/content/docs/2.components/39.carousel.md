#vue
`GoopCarousel` is shadcn-vue's Carousel, built on the same [Embla Carousel](https://www.embla-carousel.com/) (`embla-carousel-vue`, installed with `@goopui/vue`), with the same parts and API: `GoopCarouselContent`, `GoopCarouselItem`, `GoopCarouselPrevious`, `GoopCarouselNext`, `useCarousel`, `orientation`, `opts`, `plugins` and `@init-api` (or `setApi`). Embla still does all the scrolling. The goo reads the slides' real motion and never changes it. `GoopCarouselDots` is a goopUI addition.

#react
`GoopCarousel` is shadcn/ui's Carousel, built on the same [Embla Carousel](https://www.embla-carousel.com/) (`embla-carousel-react`, installed with `@goopui/react`), with the same parts and API: `GoopCarouselContent`, `GoopCarouselItem`, `GoopCarouselPrevious`, `GoopCarouselNext`, `useCarousel`, `orientation`, `opts`, `plugins` and `setApi`. Embla still does all the scrolling. The goo reads the slides' real motion and never changes it. `GoopCarouselDots` is a goopUI addition.

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopCarousel*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--background`, `--card`, `--border`, `--primary`, `--ring`, `--radius`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
```bash
pnpm add @goopui/react
```

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

That one line adds the styles and points Tailwind at the component classes. It works the same in Next.js and Vite; see [Installation](/docs/getting-started/installation#nextjs). You don't install `embla-carousel-react` yourself.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopCard,
  GoopCarousel,
  GoopCarouselContent,
  GoopCarouselDots,
  GoopCarouselItem,
  GoopCarouselNext,
  GoopCarouselPrevious,
} from '@goopui/vue'
</script>

<template>
  <GoopCarousel class="w-full max-w-xs">
    <GoopCarouselContent>
      <GoopCarouselItem v-for="i in 5" :key="i">
        <div class="p-1">
          <GoopCard class="aspect-square items-center justify-center">
            <span class="text-4xl font-semibold">{{ i }}</span>
          </GoopCard>
        </div>
      </GoopCarouselItem>
    </GoopCarouselContent>
    <GoopCarouselPrevious />
    <GoopCarouselNext />
    <GoopCarouselDots class="mt-4" />
  </GoopCarousel>
</template>
```

#react
```tsx
import {
  GoopCard,
  GoopCarousel,
  GoopCarouselContent,
  GoopCarouselDots,
  GoopCarouselItem,
  GoopCarouselNext,
  GoopCarouselPrevious,
} from '@goopui/react'

export function Slides() {
  return (
    <GoopCarousel className="w-full max-w-xs">
      <GoopCarouselContent>
        {Array.from({ length: 5 }, (_, i) => (
          <GoopCarouselItem key={i}>
            <div className="p-1">
              <GoopCard className="aspect-square items-center justify-center">
                <span className="text-4xl font-semibold">{i + 1}</span>
              </GoopCard>
            </div>
          </GoopCarouselItem>
        ))}
      </GoopCarouselContent>
      <GoopCarouselPrevious />
      <GoopCarouselNext />
      <GoopCarouselDots className="mt-4" />
    </GoopCarousel>
  )
}
```
::

Set the goo props on `GoopCarousel`. Every part reads them from there.

## Behavior

- **Stretch.** While you drag or fling, each slide stretches a little along the motion and thins a touch across it, with momentum. When it snaps and stops, it overshoots into a slight squash and wobbles back like jelly (`stretch`).
- **Slosh.** The slides' leading and trailing edges are goo: the trailing edge drags a low, wide mound behind while they travel, and braking pushes one out of the leading edge (`slosh`). The mounds land in a different place every time.
- **Rubber band.** Drag past the first or last slide and its outer edge reaches back toward the carousel's edge as one low, wide mound, springing back when you let go (`rubberBand`). It never crosses the edge, so it's never clipped. Loops have no ends, so no band.
- **Dots.** In `GoopCarouselDots` the active dot is one goo blob that flows to the next dot with momentum and lands with a jelly overshoot (`dots`), like the Tabs indicator.
- **Previous and Next** are `GoopButton`s: they squish when pressed (`squish`).
- **No layout shift.** The stretch uses the CSS `scale` property, and the goo is drawn behind each slide's content in the slide's own colour. Nothing changes size or position, the page's scroll size never changes, and text is never filtered.
- **Which element jellies.** The goo redraws the slide's surface: the first element that paints a background, like a `GoopCard`. Mark another one with `data-goop-surface`.

## Tuning

Change the feel, keep only the rubber band, or go plain shadcn:

::preview{:controls="false"}
:demo-carousel{set="plain"}
::

::fw
#vue
```vue
<GoopCarousel preset="wild">...</GoopCarousel>
<GoopCarousel :stretch="false" :slosh="false">...</GoopCarousel>
<GoopCarousel :goo="false">...</GoopCarousel>
```

`stretch`, `slosh` and `rubberBand` also take a strength from `0` to `2`. `:dots="false"` gives flat dots, `:squish="false"` stops the button squish, and `:goo="false"` renders exactly shadcn's Carousel.

#react
```tsx
<GoopCarousel preset="wild">...</GoopCarousel>
<GoopCarousel stretch={false} slosh={false}>...</GoopCarousel>
<GoopCarousel goo={false}>...</GoopCarousel>
```

`stretch`, `slosh` and `rubberBand` also take a strength from `0` to `2`. `dots={false}` gives flat dots, `squish={false}` stops the button squish, and `goo={false}` renders exactly shadcn's Carousel.

## API

::fw
#vue
Get embla's API with `@init-api` (shadcn-vue) or `setApi` (shadcn React's name), or call `useCarousel()` inside the carousel for `carouselApi`, `scrollPrev`, `scrollNext`, `scrollTo`, `canScrollPrev`, `canScrollNext` and `selectedIndex`. Plugins go in `plugins`, exactly as with shadcn:

```vue
<script setup lang="ts">
import Autoplay from 'embla-carousel-autoplay'
</script>

<template>
  <GoopCarousel :plugins="[Autoplay({ delay: 2000 })]">...</GoopCarousel>
</template>
```

#react
Get embla's API with `setApi`, as in shadcn, or call `useCarousel()` inside the carousel for `api`, `scrollPrev`, `scrollNext`, `scrollTo`, `canScrollPrev`, `canScrollNext` and `selectedIndex`. Plugins go in `plugins`, exactly as with shadcn:

```tsx
import Autoplay from 'embla-carousel-autoplay'

<GoopCarousel plugins={[Autoplay({ delay: 2000 })]}>...</GoopCarousel>
```

## Props

::fw
#vue
`GoopCarousel` takes shadcn-vue's Carousel props, `class`, `as` / `asChild`, and these. `GoopCarouselItem`, `GoopCarouselPrevious` and `GoopCarouselNext` take `class` and `asChild`; Previous and Next also take `variant` and `size`.

#react
`GoopCarousel` takes shadcn/ui's Carousel props, the `div` props, and these. `GoopCarouselContent` and `GoopCarouselItem` take the `div` props; `GoopCarouselPrevious` and `GoopCarouselNext` take `GoopButton`'s props (`variant` defaults to `outline`, `size` to `icon-sm`).

## Accessibility

::fw
#vue
It's shadcn's carousel: a focusable `region` with `aria-roledescription="carousel"`, the arrow keys move between slides, each slide is a `group` with `aria-roledescription="slide"` and an "N of M" label (unless you set your own), and Previous / Next disable themselves at the ends. The dots are buttons labelled "Go to slide N", with `aria-current` on the active one. The goo is `aria-hidden`. Under reduced motion there's no stretch, slosh or band, Previous / Next and the dots jump instead of gliding, and the dot blob snaps. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
It's shadcn's carousel: a `region` with `aria-roledescription="carousel"`, the arrow keys move between slides while focus is inside it, each slide is a `group` with `aria-roledescription="slide"` and an "N of M" label (unless you set your own), and Previous / Next disable themselves at the ends. The dots are buttons labelled "Go to slide N", with `aria-current` on the active one. The goo is `aria-hidden` and starts after hydration. Under reduced motion there's no stretch, slosh or band, Previous / Next and the dots jump instead of gliding, and the dot blob snaps. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
