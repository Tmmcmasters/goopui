#vue
`GoopBreadcrumb` has the same parts, markup and classes as shadcn-vue's Breadcrumb: `GoopBreadcrumbList`, `GoopBreadcrumbItem`, `GoopBreadcrumbLink` (reka-ui `Primitive`, so `as` and `asChild` work, e.g. with `NuxtLink`), `GoopBreadcrumbPage`, `GoopBreadcrumbSeparator` and `GoopBreadcrumbEllipsis`. Swap the imports and you're done.

#react
`GoopBreadcrumb` has the same parts, markup and classes as shadcn/ui's Breadcrumb: `GoopBreadcrumbList`, `GoopBreadcrumbItem`, `GoopBreadcrumbLink` (`asChild` via Radix Slot, e.g. with Next.js `Link`), `GoopBreadcrumbPage`, `GoopBreadcrumbSeparator` and `GoopBreadcrumbEllipsis`. Swap the imports and you're done. The item, page, separator and ellipsis have no `'use client'`, so they render in Server Components; the root, list and link are client components, because they carry the blob.

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopBreadcrumb*` part.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Breadcrumb parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopBreadcrumb,
  GoopBreadcrumbItem,
  GoopBreadcrumbLink,
  GoopBreadcrumbList,
  GoopBreadcrumbPage,
  GoopBreadcrumbSeparator,
} from '@goopui/vue'
</script>

<template>
  <GoopBreadcrumb>
    <GoopBreadcrumbList>
      <GoopBreadcrumbItem>
        <GoopBreadcrumbLink as-child>
          <NuxtLink to="/">Home</NuxtLink>
        </GoopBreadcrumbLink>
      </GoopBreadcrumbItem>
      <GoopBreadcrumbSeparator />
      <GoopBreadcrumbItem>
        <GoopBreadcrumbPage>Breadcrumb</GoopBreadcrumbPage>
      </GoopBreadcrumbItem>
    </GoopBreadcrumbList>
  </GoopBreadcrumb>
</template>
```

#react
```tsx
import {
  GoopBreadcrumb,
  GoopBreadcrumbItem,
  GoopBreadcrumbLink,
  GoopBreadcrumbList,
  GoopBreadcrumbPage,
  GoopBreadcrumbSeparator,
} from '@goopui/react'
import Link from 'next/link'

export function Trail() {
  return (
    <GoopBreadcrumb>
      <GoopBreadcrumbList>
        <GoopBreadcrumbItem>
          <GoopBreadcrumbLink asChild>
            <Link href="/">Home</Link>
          </GoopBreadcrumbLink>
        </GoopBreadcrumbItem>
        <GoopBreadcrumbSeparator />
        <GoopBreadcrumbItem>
          <GoopBreadcrumbPage>Breadcrumb</GoopBreadcrumbPage>
        </GoopBreadcrumbItem>
      </GoopBreadcrumbList>
    </GoopBreadcrumb>
  )
}
```
::

Set the goo props on `GoopBreadcrumb`; the list follows them (a prop set on `GoopBreadcrumbList` wins there).

## What it does

- **One blob.** Hovering a link lights it with a soft goo background in shadcn's muted tone. Move to the next link and the same blob flows over, stretching gently with a short tail (`momentum`) and landing softly (`wobble`). Between links it stays put, so it never flickers out; leaving the trail lets it fade.
- **It follows the pointer.** A low, wide swell of the blob sits under the cursor (`followPointer`), like the menu highlight.
- **Keyboard too.** Tabbing through the links moves the blob to the focused link.
- **No layout shift.** Under the blob each link gets a few pixels of padding for it, given back with equal negative margins, so the trail sits exactly where shadcn's does. Separators, the ellipsis and the current page are never lit.
- **Server render.** SSR renders shadcn's markup; the blob attaches in the browser.

## Props

::component-props{name="breadcrumb"}
::

::fw
#vue
`GoopBreadcrumbList` takes the same goo props (they win over the root's) and exposes `handle`, the live blob handle. Every part takes `class`.

#react
`GoopBreadcrumbList` takes the same goo props (they win over the root's); its `ref` is the `<ol>` and `goopRef` receives the live blob handle (a `MenuHighlightHandle`, `null` before mount or with `goo` off). Every part takes `className` and its element's props.
::

## Accessibility

Same as shadcn: a `<nav aria-label="breadcrumb">` around an ordered list, the current page with `aria-current="page"`, separators and the ellipsis hidden from screen readers. The blob is `aria-hidden`. Under reduced motion it snaps to the link with no travel. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
