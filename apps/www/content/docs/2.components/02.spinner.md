::fw
#vue
`GoopSpinner` keeps the shadcn-vue Spinner API: a `role="status"` element with `aria-label="Loading"`, sized with classes like `size-6`, colored with `currentColor`. shadcn's spinner is a lucide icon, so there is no reka-ui primitive underneath. The goo is added on top.

#react
`GoopSpinner` keeps the shadcn/ui Spinner API: a `role="status"` element with `aria-label="Loading"`, sized with classes like `size-6`, colored with `currentColor`. shadcn's spinner is a lucide icon, so there is no Radix primitive underneath. The goo is added on top.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopSpinner`. In plain Vue, import it from `@goopui/vue`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopSpinner` from `@goopui/react`.
::

## Variants

Five shapes. `orbit` is the default.

- `orbit`: blobs chase each other round a circle. They surge apart and catch up, so they merge and split.
- `comet`: a spinning arc with a tail.
- `ring`: a bead rolling round a donut.
- `dots`: a bead rolling along three dots.
- `pulse`: a core that buds satellites.

::fw
#vue
```vue
<GoopSpinner variant="orbit" />
<GoopSpinner variant="comet" />
<GoopSpinner variant="ring" />
<GoopSpinner variant="dots" />
<GoopSpinner variant="pulse" />
```

## Play

A spinner is playful by default (`interactive`):

- **Move** the pointer over it and the goo sloshes (`slosh`).
- **Press and drag** to pull it out in lumps. Release and it snaps back (`grab`).
- **Click or tap** to squish it. It swells back with a ripple (`pop`).

::fw
#vue
`:interactive="false"` turns all three off and makes the spinner `pointer-events: none` again. Use it for a spinner that sits on top of something clickable. `slosh`, `grab`, and `pop` each turn off on their own.

#react
`interactive={false}` turns all three off and makes the spinner `pointer-events: none` again. Use it for a spinner that sits on top of something clickable. `slosh`, `grab`, and `pop` each turn off on their own.
::

## Props

::fw
#vue
GoopSpinner keeps the shadcn-vue Spinner API (`class`) and adds the goo props.

#react
GoopSpinner keeps the shadcn/ui Spinner API (`className` and the other element props) and adds the goo props.
::

::component-props{name="spinner"}
::

::fw
#vue
It exposes `handle` (the live spinner handle, `null` before mount) and `el`.

#react
`ref` is the root `span`; `goopRef` receives the live spinner handle (`null` before mount).
::

::fw
#vue
Before it mounts, and during SSR, the spinner renders a static inline SVG of its merged pose. First paint and hydration match, and nothing shifts when the live version takes over. It pauses when it is offscreen or the tab is hidden.

#react
During SSR (Next.js server-renders it like any client component) and until hydration, the spinner renders a static inline SVG of its merged pose. First paint and hydration match, and nothing shifts when the live version takes over. It pauses when it is offscreen or the tab is hidden.
::

## Accessibility

The root is `role="status"` with `aria-label="Loading"`, the same as shadcn's. Override the label with `aria-label`.

Reduced motion keeps the goo shape and turns off the simulation: the spinner shows a still, merged pose, and the slosh, grab, and pop interactions are off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
