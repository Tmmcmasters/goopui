## Usage

```vue
<script setup lang="ts">
import { GoopButton } from '@goopui/vue'
</script>

<template>
  <GoopButton>Save</GoopButton>
  <GoopButton variant="destructive" goo="lg">Delete</GoopButton>
</template>
```

With `@goopui/nuxt` the import isn't needed, because components are auto-imported.

## Behavior

- **Hover** spawns one to three drips off the bottom edge. They swell and neck. If you keep hovering they detach, fall about 24 to 40px, shrink, and fade. If the pointer leaves first, they get pulled back up.
- **Press** squishes the body, and it springs back when you let go. Holding the press makes the drips swell faster.
- **Touch** gives a squish and one drip per tap. Hover drips only run on devices with a real hover.
- **Layout** never changes. Drips draw in an absolutely positioned overlay with `pointer-events: none`.

## API (planned)

GoopButton keeps the shadcn-vue Button API and adds two goo props.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'destructive' \| 'outline' \| 'secondary' \| 'ghost' \| 'link'` | `'default'` | Same as shadcn. The goo takes the variant's background color. Outline and ghost use a goo stroke layer. |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon'` | `'default'` | Same as shadcn. |
| `goo` | `'sm' \| 'md' \| 'lg'` | `'md'` | Goo amount preset (blur, drip size, drip length). |
| `drip` | `boolean` | `true` | `false` keeps the goo body and squish but never drips. |
| `as` / `asChild` | | | Same as shadcn, via reka-ui's `Primitive`. |
| `class` | `string` | | Merged onto the root element, like shadcn. |

For anything the presets don't cover, use the [`--goop-*` variables](/docs/getting-started/theming).

## Accessibility

It's a real `<button>` (or your `asChild` element). The goo layer is `aria-hidden` and can't be clicked, the label is never filtered, and your focus ring isn't covered. Under reduced motion the shape and resting drips stay, and the drip simulation and squish turn off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
