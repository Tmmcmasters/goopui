## Usage

```vue
<script setup lang="ts">
import { GoopButton } from '@goopui/vue'
</script>

<template>
  <GoopButton>Save</GoopButton>
  <GoopButton variant="destructive" goo="lg">Delete</GoopButton>
</template>
```

With `@goopui/nuxt` the import isn't needed, because components are auto-imported.

## Behavior

- **Hover** spawns drips off the bottom edge. They swell and neck. If you keep hovering they detach, fall, shrink, and fade; if the pointer leaves first, they get pulled back up. Resting the pointer keeps a slow drip going (`--goop-drip-interval`).
- **Speed** matters. A fast entry spawns more drips in a tighter cluster, and past `--goop-splash-threshold` the pointer punches goo straight out the far side.
- **Momentum.** The body leans and wobbles with the pointer, hanging drips swing with its acceleration (`--goop-inertia`) and creep along the edge toward the cursor (`--goop-flow`), and fast page scrolls make them slosh (`--goop-scroll-slosh`).
- **Click** squishes the body, then on release adds goo (it swells and drips faster) and fires a shockwave from the click point. Space and Enter do the same from the top.
- **Touch** gives a squish, a drip, and a shockwave per tap. Hover drips only run on devices with a real hover.
- **Layout** never changes. Drips and particles draw in an absolutely positioned overlay with `pointer-events: none`.

## Resting drips

`--goop-resting-drips` hangs still drips off the edge. In JS you can place them, as fractions of the width. They're static, so they're also what's left in reduced-motion mode:

::preview{:controls="false"}
:demo-buttons{set="resting"}
::

```css
.save-button {
  --goop-resting-drips: 2;
}
```

## Oil finish

`finish: 'oil'` (or `--goop-finish: oil`) gives the goo a thin-film sheen. It works on any color, and is strongest on dark ink:

::preview
:demo-buttons{set="oil"}
::

```css
.crude-oil {
  --goop-color: oklch(0.17 0.01 60);
  --goop-finish: oil;
  --goop-oil-intensity: 0.6;
}
```

## Disabled and drip-free

## API (planned)

GoopButton keeps the shadcn-vue Button API and adds two goo props.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'destructive' \| 'outline' \| 'secondary' \| 'ghost' \| 'link'` | `'default'` | Same as shadcn. The goo takes the variant's background color. Outline and ghost use a goo stroke layer. |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon'` | `'default'` | Same as shadcn. |
| `goo` | `'sm' \| 'md' \| 'lg'` | `'md'` | Goo amount preset (blur, drip size, drip length). |
| `drip` | `boolean` | `true` | `false` keeps the goo body and squish but never drips. |
| `splash` | `'near' \| 'escape' \| 'off'` | `'near'` | Where splashes and shockwave particles go. |
| `finish` | `'solid' \| 'oil'` | `'solid'` | Surface finish. |
| `as` / `asChild` | | | Same as shadcn, via reka-ui's `Primitive`. |
| `class` | `string` | | Merged onto the root element, like shadcn. |

For anything the presets don't cover, use the [`--goop-*` variables](/docs/getting-started/theming).

## Accessibility

It's a real `<button>` (or your `asChild` element). The goo layer is `aria-hidden` and can't be clicked, the label is never filtered, and your focus ring isn't covered. Space and Enter get the same squish and shockwave as a click. Under reduced motion the shape and resting drips stay; drips, squish, momentum, splashes, and shockwaves turn off, and an oil sheen holds still. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
