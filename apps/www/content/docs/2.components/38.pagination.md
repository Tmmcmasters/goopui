#vue
`GoopPagination` wraps the same [reka-ui Pagination](https://reka-ui.com/docs/components/pagination) primitive as shadcn-vue's Pagination, with the same parts and API: `GoopPaginationContent`, `GoopPaginationItem`, `GoopPaginationEllipsis`, `GoopPaginationFirst`, `GoopPaginationPrevious`, `GoopPaginationNext`, `GoopPaginationLast` and `GoopPaginationLink`. Swap the imports and you're done.

#react
`GoopPagination` is shadcn/ui's Pagination, with the same parts and markup: `GoopPaginationContent`, `GoopPaginationItem`, `GoopPaginationLink`, `GoopPaginationPrevious`, `GoopPaginationNext` and `GoopPaginationEllipsis`. Like shadcn/ui's, it holds no page state: you keep the current page yourself and mark its link with `isActive`. `GoopPaginationFirst` and `GoopPaginationLast` are goopUI extras (shadcn/ui has none). Swap the imports and you're done.
::

## Installation

::fw{when="vue"}
### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopPagination*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--background`, `--border`, `--input`, `--muted`, `--foreground`, `--ring`, `--radius`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```
::

::fw{when="react"}
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import the Pagination parts from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import {
  GoopPagination,
  GoopPaginationContent,
  GoopPaginationEllipsis,
  GoopPaginationItem,
  GoopPaginationNext,
  GoopPaginationPrevious,
} from '@goopui/vue'
</script>

<template>
  <GoopPagination v-slot="{ page }" :items-per-page="10" :total="100" :default-page="2">
    <GoopPaginationContent v-slot="{ items }">
      <GoopPaginationPrevious />
      <template v-for="(item, index) in items" :key="index">
        <GoopPaginationItem v-if="item.type === 'page'" :value="item.value" :is-active="item.value === page">
          {{ item.value }}
        </GoopPaginationItem>
        <GoopPaginationEllipsis v-else :index="index" />
      </template>
      <GoopPaginationNext />
    </GoopPaginationContent>
  </GoopPagination>
</template>
```

#react
```tsx
'use client'
import { useState } from 'react'
import {
  GoopPagination,
  GoopPaginationContent,
  GoopPaginationEllipsis,
  GoopPaginationItem,
  GoopPaginationLink,
  GoopPaginationNext,
  GoopPaginationPrevious,
} from '@goopui/react'

export function Pages() {
  const [page, setPage] = useState(2)
  return (
    <GoopPagination>
      <GoopPaginationContent>
        <GoopPaginationItem>
          <GoopPaginationPrevious
            href="#"
            onClick={(e) => {
              e.preventDefault()
              setPage((p) => Math.max(1, p - 1))
            }}
          />
        </GoopPaginationItem>
        {[1, 2, 3].map((n) => (
          <GoopPaginationItem key={n}>
            <GoopPaginationLink
              href="#"
              isActive={n === page}
              onClick={(e) => {
                e.preventDefault()
                setPage(n)
              }}
            >
              {n}
            </GoopPaginationLink>
          </GoopPaginationItem>
        ))}
        <GoopPaginationItem>
          <GoopPaginationEllipsis />
        </GoopPaginationItem>
        <GoopPaginationItem>
          <GoopPaginationNext
            href="#"
            onClick={(e) => {
              e.preventDefault()
              setPage((p) => p + 1)
            }}
          />
        </GoopPaginationItem>
      </GoopPaginationContent>
    </GoopPagination>
  )
}
```

With real routes, give each link its page's `href` and set `isActive` from the URL.
::

Set the goo props on `GoopPagination` and every part follows them. A prop set on a part wins there (the blob lives on `GoopPaginationContent`, the press squish on the button parts).

## Behavior

- **The blob** is the current page's outline button. When the page changes it slides to the new number with momentum, stretches gently with a short tail, and lands with a jelly overshoot (`momentum`, `wobble`). A jump over several pages, like First or Last, is one long slide.
::fw
#vue
- **It follows everything.** Clicks, Previous / Next, and `v-model:page`. It tracks the item with `is-active`, or reka-ui's current page when you leave `is-active` out.

#react
- **It follows `isActive`.** The blob sits on the `GoopPaginationLink` with `isActive`, so it follows whatever moves that: clicks, Previous / Next, the URL, or your own state.
::

- **Previous, Next, First and Last** are ghost `GoopButton`s: they squish when pressed (`press`) and get the ghost hover goo.
- **Labels stay sharp.** The blob is `aria-hidden` and sits behind the real page numbers. Text is never filtered.
- **Server render.** SSR renders shadcn's markup, and the current page is styled until the blob attaches in the browser.

## Tuning

Change the feel, turn off the jelly and the stretch, or go plain shadcn:

::preview{:controls="false"}
:demo-pagination{set="plain"}
::

::fw
#vue
```vue
<GoopPagination preset="wild">...</GoopPagination>
<GoopPagination :wobble="false" :momentum="false">...</GoopPagination>
<GoopPagination :goo="false">...</GoopPagination>
```

`:indicator="false"` keeps the buttons' goo but gives the current page shadcn's outline button. `:press="false"` stops the button squish. `:goo="false"` renders exactly shadcn's Pagination.

#react
```tsx
<GoopPagination preset="wild">...</GoopPagination>
<GoopPagination wobble={false} momentum={false}>...</GoopPagination>
<GoopPagination goo={false}>...</GoopPagination>
```

`indicator={false}` keeps the buttons' goo but gives the current page shadcn's outline button. `press={false}` stops the button squish. `goo={false}` renders exactly shadcn's Pagination.

## Accessibility

::fw
#vue
It's reka-ui's Pagination: page buttons with `aria-label="Page n"` and `aria-current="page"` on the current one, and Previous / Next / First / Last buttons that disable themselves at the ends. Under reduced motion the blob snaps to the new page with no stretch or overshoot, and still marks it. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
It's shadcn/ui's markup: a `<nav aria-label="pagination">` around a list of links, `aria-current="page"` on the link with `isActive`, and Previous / Next / First / Last labelled "Go to previous page" and so on. They're plain links, so stopping at the ends is up to you. Under reduced motion the blob snaps to the new page with no stretch or overshoot, and still marks it. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
::
