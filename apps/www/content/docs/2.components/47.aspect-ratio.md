::fw
#vue
`GoopAspectRatio` wraps reka-ui's [`AspectRatio`](https://reka-ui.com/docs/components/aspect-ratio), like shadcn-vue's Aspect Ratio. It has no goo: it only sizes a box, so goo there would be noise. Put goo components inside it instead.

#react
`GoopAspectRatio` wraps [Radix AspectRatio](https://www.radix-ui.com/primitives/docs/components/aspect-ratio), like shadcn/ui's Aspect Ratio. It has no goo: it only sizes a box, so goo there would be noise. Put goo components inside it instead.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopAspectRatio`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopAspectRatio` from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<div class="w-full max-w-sm">
  <GoopAspectRatio :ratio="16 / 9" class="rounded-lg bg-muted">
    <img src="/photo.jpg" alt="Photo" class="size-full rounded-lg object-cover" />
  </GoopAspectRatio>
</div>
```

#react
```tsx
<div className="w-full max-w-sm">
  <GoopAspectRatio ratio={16 / 9} className="rounded-lg bg-muted">
    <img src="/photo.jpg" alt="Photo" className="size-full rounded-lg object-cover" />
  </GoopAspectRatio>
</div>
```
