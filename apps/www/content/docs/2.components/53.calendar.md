#vue
`GoopCalendar` and its parts (`GoopCalendarHeader`, `GoopCalendarHeading`, `GoopCalendarPrevButton`, `GoopCalendarNextButton`, `GoopCalendarGrid`, `GoopCalendarGridHead`, `GoopCalendarGridBody`, `GoopCalendarGridRow`, `GoopCalendarHeadCell`, `GoopCalendarCell`, `GoopCalendarCellTrigger`) are shadcn-vue's Calendar on reka-ui's Calendar, with the same markup, classes and props (`v-model`, `v-model:placeholder`, `locale`, `week-starts-on`, `number-of-months`, `min-value`, `max-value`, `is-date-disabled`, ...). Swap the imports and you're done.

#react
`GoopCalendar` is shadcn/ui's Calendar on [react-day-picker](https://daypicker.dev), with the same markup, classes and props (`mode`, `selected` / `onSelect`, `month` / `onMonthChange`, `locale`, `weekStartsOn`, `numberOfMonths`, `disabled`, `captionLayout`, `buttonVariant`, `classNames`, `components`, ...), and `GoopCalendarDayButton` is shadcn's `CalendarDayButton`. Swap the import and you're done. It is a client component.

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports every `GoopCalendar*` part. Dates are [`@internationalized/date`](https://react-spectrum.adobe.com/internationalized/date/) values, like reka-ui's:

```bash
pnpm add @internationalized/date
```

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopCalendar` from `@goopui/react`. react-day-picker comes with it; dates are plain `Date`s (and `DateRange`, `{ from, to }`, is exported from `@goopui/react` too).
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports GoopCalendar. In plain Vue, import it:
import { GoopCalendar } from '@goopui/vue'
import { getLocalTimeZone, today, type DateValue } from '@internationalized/date'
import { shallowRef } from 'vue'

// shallowRef keeps the date a real CalendarDate (a deep ref's type would unwrap it).
const date = shallowRef<DateValue>(today(getLocalTimeZone()))
</script>

<template>
  <GoopCalendar v-model="date" class="rounded-lg border" />
</template>
```

The `calendar-heading`, `calendar-prev-icon` and `calendar-next-icon` slots replace the heading and the arrows, as in shadcn-vue.

#react
```tsx
import { GoopCalendar } from '@goopui/react'
import { useState } from 'react'

export function DatePicker() {
  const [date, setDate] = useState<Date | undefined>(new Date())
  return <GoopCalendar mode="single" selected={date} onSelect={setDate} className="rounded-lg border" />
}
```

`components` replaces react-day-picker's parts (the chevrons, the day button, ...), as in shadcn/ui.

## What it does

- **flow.** Picking a new day makes the selected goo travel there: it gathers in the old day, necks out, pinches off, travels and floods the new day from the side it arrives on, while the label colour follows the goo's edge.
- **pulse.** A small jelly pulse as it lands.
- **slosh.** Paging the month (the arrows, PageUp / PageDown, or arrowing past the end of the month) gives the days a gentle slosh the way the month moved: each column swings a few px and springs back, in a wave from the leading side.
- **focus.** The hover and keyboard-focus highlight is one soft goo wash that glides from day to day, so arrow-key navigation visibly moves the goo. Touch never leaves it behind.
- **No layout shift.** The goo is painted on layers under the day buttons, outside the layout. The slosh only moves the days with `translate`, and they're back in place within about two thirds of a second.
- **Reduced motion.** The selection is a static fill, the wash snaps to the day, and the month doesn't slosh.

## States

::fw
#vue
Disabled days (`is-date-disabled`) are skipped by the wash. The `wild` preset sloshes further; `goo` set to false renders a plain shadcn Calendar.

#react
Disabled days (`disabled`) are skipped by the wash. The `wild` preset sloshes further; `goo` set to false renders a plain shadcn Calendar.
::

::fw
#vue
`GoopCalendar` exposes `handle` (the live `CalendarHandle`) and `el` (the root). Every part takes `class`. Theme the goo with `--goop-calendar-selected` (default `--primary`) and `--goop-calendar-text` (the label on it, default `--primary-foreground`).

#react
`GoopCalendar`'s `ref` is the root and `goopRef` receives the live `CalendarHandle`. Theme the goo with `--goop-calendar-selected` (default `--primary`) and `--goop-calendar-text` (the label on it, default `--primary-foreground`).
::

## Accessibility

::fw
#vue
Same markup and keyboard as reka-ui's Calendar: a labelled grid, arrow keys move between days, PageUp / PageDown page the month, Home / End jump to the week's ends. The goo layers and the label copies on them are `aria-hidden`. See [Accessibility & reduced motion](/docs/getting-started/accessibility).

#react
Same markup and keyboard as react-day-picker: a labelled grid, arrow keys move between days, PageUp / PageDown page the month, Home / End jump to the week's ends. The goo layers and the label copies on them are `aria-hidden`. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
::
