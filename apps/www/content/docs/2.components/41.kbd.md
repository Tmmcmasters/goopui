## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopKbd, GoopKbdGroup } from '@goopui/vue'
</script>

<template>
  <GoopKbdGroup>
    <GoopKbd :keys="['Meta']">⌘</GoopKbd>
    <GoopKbd :keys="['Meta', 'K']">K</GoopKbd>
  </GoopKbdGroup>
</template>
```

#react
```tsx
import { GoopKbd, GoopKbdGroup } from '@goopui/react'

export function SearchShortcut() {
  return (
    <GoopKbdGroup>
      <GoopKbd keys={['Meta']}>⌘</GoopKbd>
      <GoopKbd keys={['Meta', 'K']}>K</GoopKbd>
    </GoopKbdGroup>
  )
}
```

## What it does

- **press.** Click a key, or press the keys listed in `keys`, and it squishes into its base: a little shorter, a little wider, sunk by about a pixel. Let go and it springs back with a small jelly rebound. A quick tap still shows a full press.
- **keys is opt-in.** `['Meta', 'K']` presses on ⌘K only (every key held), not on K alone. Use `KeyboardEvent.key` names, plus `Cmd` / `⌘`, `Ctrl`, `Option` / `⌥`, `Shift` / `⇧` and `Esc`. Without `keys` only a click presses it.
- **No layout shift.** The squish is a transform on the key itself, so nothing around it moves.
- **Clickable.** shadcn's Kbd ignores the pointer (`pointer-events-none`). While the squish is on, `GoopKbd` takes clicks; a click still reaches whatever it sits in (a button, a tooltip trigger).
- `GoopKbdGroup` is plain.

## Props

::component-props{name="kbd"}
::

::fw
#vue
`GoopKbdGroup` takes `class`. `:goo="false"` (or `:press="false"`) renders exactly shadcn's Kbd. `GoopKbd` exposes `tap()` to play a press from code.

#react
`GoopKbdGroup` takes `className` and the `kbd` props. `goo={false}` (or `press={false}`) renders exactly shadcn's Kbd. On `GoopKbd`, `ref` is the `<kbd>` element and `goopRef` receives the live `KbdHandle` (`null` before mount or with `goo` off); call its `tap()` to play a press from code.
::

## Accessibility

It's a plain `<kbd>`, so screen readers read the key. The listeners only watch the keyboard; they never prevent a shortcut. Under reduced motion the keys stay still. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
