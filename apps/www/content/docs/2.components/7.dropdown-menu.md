`GoopDropdownMenu` wraps the same [reka-ui Dropdown Menu](https://reka-ui.com/docs/components/dropdown-menu) primitive as shadcn-vue's DropdownMenu, with the same API. Keyboard navigation, typeahead, focus handling, and positioning work the same. Swap the imports and you're done.

## Installation

### Nuxt

```bash
pnpm add @goopui/nuxt
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every `GoopDropdownMenu*` part, adds `goop.css`, and points Tailwind at the component classes. It needs Tailwind CSS v4 and the shadcn tokens (`--popover`, `--popover-foreground`, `--primary`, `--accent`, `--destructive`, `--ring`, `--radius`).

### Vue

```bash
pnpm add @goopui/vue
```

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```

## Usage

```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them from '@goopui/vue'.
import {
  GoopButton,
  GoopDropdownMenu,
  GoopDropdownMenuContent,
  GoopDropdownMenuGroup,
  GoopDropdownMenuItem,
  GoopDropdownMenuLabel,
  GoopDropdownMenuSeparator,
  GoopDropdownMenuShortcut,
  GoopDropdownMenuTrigger,
} from '@goopui/vue'
</script>

<template>
  <GoopDropdownMenu>
    <GoopDropdownMenuTrigger as-child>
      <GoopButton variant="outline">Open menu</GoopButton>
    </GoopDropdownMenuTrigger>
    <GoopDropdownMenuContent class="w-48">
      <GoopDropdownMenuLabel>My account</GoopDropdownMenuLabel>
      <GoopDropdownMenuGroup>
        <GoopDropdownMenuItem>Profile <GoopDropdownMenuShortcut>⇧⌘P</GoopDropdownMenuShortcut></GoopDropdownMenuItem>
        <GoopDropdownMenuItem>Settings <GoopDropdownMenuShortcut>⌘,</GoopDropdownMenuShortcut></GoopDropdownMenuItem>
        <GoopDropdownMenuItem disabled>Billing</GoopDropdownMenuItem>
      </GoopDropdownMenuGroup>
      <GoopDropdownMenuSeparator />
      <GoopDropdownMenuItem variant="destructive">Log out</GoopDropdownMenuItem>
    </GoopDropdownMenuContent>
  </GoopDropdownMenu>
</template>
```

The parts are `GoopDropdownMenu`, `Trigger`, `Content`, `Portal`, `Group`, `Label`, `Item`, `CheckboxItem`, `RadioGroup`, `RadioItem`, `Separator`, `Shortcut`, `Sub`, `SubTrigger`, and `SubContent`, each prefixed with `GoopDropdownMenu`. The goo lives on `Content` and `SubContent`.

## Behavior

- **Open.** The panel oozes out of the trigger like the [Popover](/docs/components/popover): a bulb swells from the trigger edge, the panel inflates out of it, and the neck stretches and snaps. The far edge sloshes and sheds drops.
- **Highlight blob.** The highlighted item gets a goo blob that slides between items with momentum, stretching with a neck while it travels and landing with a jelly overshoot. It follows the pointer and the keyboard.
- **Select pop.** Choosing an item squishes the blob, and the menu closes once that has played. Call `event.preventDefault()` in `@select` to keep the menu open.
- **Submenus** emerge from their row with the same bridge and have their own highlight.
- **Close.** The goo is sucked back toward the trigger.
- **Items stay sharp.** Only the panel background, ring, shadow, and highlight are goo, drawn behind your items. Text and icons are never filtered.

## Checkboxes and radios

`CheckboxItem` and `RadioItem` work like shadcn's. The blob highlights them the same way:

:demo-dropdown-menu{set="checks"}
::

```vue
<GoopDropdownMenuCheckboxItem v-model="statusBar">Status bar</GoopDropdownMenuCheckboxItem>
<GoopDropdownMenuSeparator />
<GoopDropdownMenuRadioGroup v-model="position">
  <GoopDropdownMenuRadioItem value="top">Top</GoopDropdownMenuRadioItem>
  <GoopDropdownMenuRadioItem value="bottom">Bottom</GoopDropdownMenuRadioItem>
</GoopDropdownMenuRadioGroup>
```

## Submenus

```vue
<GoopDropdownMenuSub>
  <GoopDropdownMenuSubTrigger>Send to</GoopDropdownMenuSubTrigger>
  <GoopDropdownMenuSubContent>
    <GoopDropdownMenuItem>Email</GoopDropdownMenuItem>
    <GoopDropdownMenuItem>Message</GoopDropdownMenuItem>
  </GoopDropdownMenuSubContent>
</GoopDropdownMenuSub>
```

::preview{:controls="false"}

Goo props you leave unset on `SubContent` inherit from the parent menu. `:submenus="false"` on the parent makes every submenu a plain shadcn one.

## Surface color

By default the panel takes the trigger's color: the whole goo uses the trigger's background and the items use its text color. If the trigger has no background of its own, the theme's primary is used. Set `surface="popover"` for shadcn's popover tokens, or pass any CSS color. Submenus that don't set `surface` reuse their parent's resolved colors.

```vue
<GoopDropdownMenuContent surface="popover">...</GoopDropdownMenuContent>
<GoopDropdownMenuContent surface="oklch(0.55 0.22 290)">...</GoopDropdownMenuContent>
```

## Burst knobs

The open burst has the same four knobs as the Popover: `openDripAmount`, `openDripSize`, `openDripFling`, and `openDripVariety`. On a menu, `openDrips` is a plain boolean.

```vue
<GoopDropdownMenuContent :open-drip-amount="2" :open-drip-fling="1.5">...</GoopDropdownMenuContent>
```

## Turning parts off

Each effect is its own prop. Turn off the highlight blob, the burst, or all the goo:

::preview{:controls="false"}
:demo-dropdown-menu{set="plain"}
::

```vue
<GoopDropdownMenuContent :highlight="false" :open-drips="false">...</GoopDropdownMenuContent>
<GoopDropdownMenuContent surface="popover">...</GoopDropdownMenuContent>
<GoopDropdownMenuContent :goo="false">...</GoopDropdownMenuContent>
```

`:goo="false"` renders exactly shadcn's DropdownMenuContent.

## Driving it from code

`GoopDropdownMenuContent` exposes `handle` (the panel's engine handle) and `highlight` (the blob's handle). Both are `null` before mount or when the goo is off.

## Props

The root, trigger, group, label, separator, shortcut, and sub parts take shadcn-vue's props. `Item` also takes `inset` and `variant="destructive"`, like shadcn. `GoopDropdownMenuContent` and `GoopDropdownMenuSubContent` take reka-ui's props (`side`, `align`, `sideOffset`, ...), `class`, and these goo props. Defaults are `align="start"` and `sideOffset="4"`.

## Accessibility

Keyboard navigation, typeahead, focus management, and ARIA roles come from reka-ui. The goo surface and blob are `aria-hidden` and can't be clicked, and your items are never filtered. Under reduced motion the menu opens and closes plainly: the panel keeps its goo shape and color, the highlight blob snaps between items with no pop, and the bridge, slosh, and drops are turned off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
