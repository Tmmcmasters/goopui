::fw
#vue
`GoopLabel` wraps reka-ui's [`Label`](https://reka-ui.com/docs/components/label), like shadcn-vue's Label, with the same classes. It has no goo. It dims with a disabled peer or group, as shadcn's does.

#react
`GoopLabel` wraps [Radix Label](https://www.radix-ui.com/primitives/docs/components/label), like shadcn/ui's Label, with the same classes. It has no goo. It dims with a disabled peer or group, as shadcn's does. It has no `'use client'`, so it renders in Server Components.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopLabel`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopLabel` from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<GoopLabel for="email">Email</GoopLabel>
<GoopInput id="email" type="email" placeholder="you@example.com" />
```

#react
```tsx
<GoopLabel htmlFor="email">Email</GoopLabel>
<Input id="email" type="email" placeholder="you@example.com" />
```

`@goopui/react` has no `GoopInput` yet, so the field here is shadcn/ui's own `Input`.
