#vue
`GoopTagsInput`, `GoopTagsInputItem`, `GoopTagsInputItemText`, `GoopTagsInputItemDelete` and `GoopTagsInputInput` are shadcn-vue's TagsInput parts on reka-ui's TagsInput, with the same markup, classes and props (`v-model`, `add-on-paste`, `add-on-tab`, `add-on-blur`, `duplicate`, `delimiter`, `max`, `disabled`, ...). Swap the imports and you're done.

#react
shadcn/ui has no Tags Input for React, so **this one is goopUI's own**. It mirrors shadcn-vue's (reka-ui's TagsInput) part for part, with the same classes and keyboard, so it looks and behaves like the Vue one: `GoopTagsInput`, `GoopTagsInputItem`, `GoopTagsInputItemText`, `GoopTagsInputItemDelete` and `GoopTagsInputInput`. Tags are strings; reka's root props come in React shape (`value` / `defaultValue` / `onValueChange`, `addOnPaste`, `addOnTab`, `addOnBlur`, `duplicate`, `delimiter`, `max`, `onAddTag`, `onRemoveTag`, `onInvalid`). Every part is a client component.

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports these. In plain Vue, import them:
import { GoopTagsInput, GoopTagsInputInput, GoopTagsInputItem, GoopTagsInputItemDelete, GoopTagsInputItemText } from '@goopui/vue'
import { ref } from 'vue'

const tags = ref(['Vue', 'React', 'Svelte'])
</script>

<template>
  <GoopTagsInput v-model="tags">
    <GoopTagsInputItem v-for="tag in tags" :key="tag" :value="tag">
      <GoopTagsInputItemText />
      <GoopTagsInputItemDelete />
    </GoopTagsInputItem>
    <GoopTagsInputInput placeholder="Add a framework…" />
  </GoopTagsInput>
</template>
```

#react
```tsx
import { GoopTagsInput, GoopTagsInputInput, GoopTagsInputItem, GoopTagsInputItemDelete, GoopTagsInputItemText } from '@goopui/react'
import { useState } from 'react'

export function Frameworks() {
  const [tags, setTags] = useState(['Vue', 'React', 'Svelte'])
  return (
    <GoopTagsInput value={tags} onValueChange={setTags}>
      {tags.map((tag) => (
        <GoopTagsInputItem key={tag} value={tag}>
          <GoopTagsInputItemText />
          <GoopTagsInputItemDelete />
        </GoopTagsInputItem>
      ))}
      <GoopTagsInputInput placeholder="Add a framework…" />
    </GoopTagsInput>
  )
}
```
::

Enter (or the delimiter, `,` by default) adds what you typed. On an empty field, Backspace selects the last tag and a second Backspace removes it; the arrow keys move the selection.

## What it does

- **merge.** A new tag plops in like a droplet joining the others: a small, round drop of the tag's own colour spreads into the tag with a little jelly overshoot, while a short goo bridge to the tag before it swells and pinches off. The real tag fades in and rides the goo, so the goo ends up hidden behind it.
- **melt.** A removed tag drains away where it was: it pinches in from both ends, sinks a little and shrinks to nothing.
- **The focus ring.** The box keeps [Input](/docs/components/input)'s goo focus ring (`flow`, `close`, `ripple`, `wobble`, `drain`, and the invalid `drip` with `aria-invalid`), drawn around the whole box rather than the text field.
- **Gentle.** Both tag effects take about a third of a second, in the tag's own muted colour. Nothing loops.
- **No layout shift.** Tags only change transform and opacity, and the goo is painted outside the layout, so nothing moves and the page's scroll size never changes.
- **Reduced motion.** No merge or melt, and a static ring.

## Paste a list

With `add-on-paste` (`addOnPaste` in React), pasted text is split on the delimiter. A RegExp delimiter splits on commas, semicolons or spaces; `max` refuses tags past the limit.

:demo-tags-input{set="paste"}
::

::fw
#vue
```vue
<GoopTagsInput v-model="emails" add-on-paste add-on-blur :max="5" :delimiter="/[,;\s]+/">
  ...
</GoopTagsInput>
```

#react
```tsx
<GoopTagsInput value={emails} onValueChange={setEmails} addOnPaste addOnBlur max={5} delimiter={/[,;\s]+/}>
  ...
</GoopTagsInput>
```

## States

`aria-invalid` on the box turns the ring destructive with a small drip. `goo` set to false renders the plain box.

## Props

::component-props{name="tags-input"}
::

::fw
#vue
`GoopTagsInputItem` takes `value` and `disabled`; `GoopTagsInputInput` takes `placeholder`, `auto-focus` and `max-length`; every part takes `class`. `GoopTagsInput` exposes `handle` (the live `TagsInputHandle`) and `el` (the box).

#react
`GoopTagsInputItem` takes `value` and `disabled`; `GoopTagsInputInput` takes the `<input>` props; every part takes `className` and forwards its `ref` to its element.
::

## Accessibility

Same markup and keyboard as reka-ui's TagsInput: the tags are labelled by their text, the delete buttons are out of the tab order (the field keeps focus), and the selected tag is `aria-current`. The goo layers are `aria-hidden`. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
