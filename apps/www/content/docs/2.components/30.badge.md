#vue
`GoopBadge` is shadcn-vue's Badge, with the same variants and classes. `as` and `asChild` come from reka-ui's `Primitive`, so a badge can render as a link, a button, or your router link.

#react
`GoopBadge` is shadcn/ui's Badge, with the same variants and classes. `asChild` renders its single child through Radix's `Slot`, so a badge can be a link, a button, or your router's `Link`.
::

## Installation

::fw
#vue
Install `@goopui/nuxt` or `@goopui/vue` as shown on the [Button page](/docs/components/button#installation). The Nuxt module auto-imports `GoopBadge`.

#react
Install `@goopui/react` and add its stylesheet as shown on the [Installation](/docs/getting-started/installation#nextjs) page, then import `GoopBadge` from `@goopui/react`.
::

## Usage

::fw
#vue
```vue
<script setup lang="ts">
// Nuxt auto-imports this. In plain Vue, import it:
import { GoopBadge } from '@goopui/vue'
</script>

<template>
  <GoopBadge>Badge</GoopBadge>
  <GoopBadge as-child>
    <a href="/changelog">Changelog</a>
  </GoopBadge>
</template>
```

#react
```tsx
import { GoopBadge } from '@goopui/react'

export function Badges() {
  return (
    <>
      <GoopBadge>Badge</GoopBadge>
      <GoopBadge asChild>
        <a href="/changelog">Changelog</a>
      </GoopBadge>
    </>
  )
}
```
::

## What it does

- **swell.** When the badge is a link or a button, hovering it grows a ring in its own colour by about 1px (on the playful preset), with a soft overshoot, so the badge plumps up like a drop of goo. The outline variant swells its border.

A badge that isn't interactive never moves. The swell is a CSS transition on Tailwind's shadow, so the focus ring still works alongside it.

::fw
#vue
Turn the swell off with `:swell="false"`, or scale it with a number (`:swell="2"` is about 2px).

#react
Turn the swell off with `swell={false}`, or scale it with a number (`swell={2}` is about 2px). The `link` variant has no background, so it doesn't swell.

## Accessibility

The badge is whatever element you render. A link badge is a real `<a>`, with your focus ring. Under reduced motion the swell is off. See [Accessibility & reduced motion](/docs/getting-started/accessibility).
