goopUI assumes the shadcn setup: Tailwind CSS v4 and the shadcn CSS variables (`--primary`, `--radius`, and so on). If you already use shadcn-vue, you have both.

## Nuxt

Install the module:

```bash
pnpm add @goopui/nuxt
```

Register it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every component and injects `goop.css`. Components get the `Goop` prefix by default, so they sit next to shadcn's without clashing:

```vue [app.vue]
<template>
  <Button variant="outline">Plain</Button>
  <GoopButton>Gooey</GoopButton>
</template>
```

Change it with the module's `prefix` option (the config key isn't final):

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
  goopui: { prefix: 'Goo' },
})
```

## Vue

Install the package:

```bash
pnpm add @goopui/vue
```

Import the stylesheet after Tailwind. It holds the `--goop-*` tokens, the keyframes, and an `@source` so Tailwind picks up the classes the components use:

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```

Then import components where you use them:

```vue [App.vue]
<script setup lang="ts">
import { GoopButton } from '@goopui/vue'
</script>

<template>
  <GoopButton>Gooey</GoopButton>
</template>
```

`@goopui/vue` depends on `reka-ui` and `@goopui/core`, so you don't install those yourself.

## React and Svelte

They're coming after the Vue API settles. Until then you can use [`@goopui/core`](/docs/core/api) directly. It works on any element.
