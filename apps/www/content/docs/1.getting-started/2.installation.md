## Requirements

::fw
#vue
- **Vue 3.5+** (or **Nuxt 3.13+ / Nuxt 4**).
- **Tailwind CSS v4**, already set up in your app (for example with `@tailwindcss/vite`). The components are styled with Tailwind utilities, like shadcn's.
- **The shadcn CSS variables** (`--primary`, `--popover`, `--radius`, and so on). If you already use shadcn-vue, you have them. If not, run `npx shadcn-vue@latest init` or copy the variables from the [shadcn-vue theming docs](https://www.shadcn-vue.com/docs/theming).
- **reka-ui** comes with `@goopui/vue` (`^2.11`), so you don't install it yourself. If you also use shadcn-vue, they can share one copy.

#react
- **React 18 or 19**: Next.js 14+ (App Router or Pages Router) or any React app (Vite, ...).
- **Tailwind CSS v4**, already set up in your app (`@tailwindcss/postcss` in Next.js, `@tailwindcss/vite` in Vite). The components are styled with Tailwind utilities, like shadcn's.
- **The shadcn CSS variables** (`--primary`, `--popover`, `--radius`, and so on). If you already use shadcn/ui, you have them. If not, run `npx shadcn@latest init` or copy the variables from the [shadcn/ui theming docs](https://ui.shadcn.com/docs/theming).
- **Radix UI** comes with `@goopui/react` (the `radix-ui` package, like shadcn/ui), so you don't install it yourself.
::

::fw{when="vue"}
## Nuxt

Install the module:

```bash
pnpm add @goopui/nuxt
```

Register it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
})
```

The module auto-imports every component and injects `goop.css`. Components get the `Goop` prefix by default, so they sit next to shadcn's without clashing:

```vue [app.vue]
<template>
  <Button variant="outline">Plain</Button>
  <GoopButton>Gooey</GoopButton>
</template>
```

Change it with the module's `prefix` option:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
  goop: { prefix: 'Goo' },
})
```

### Module options

All options go under the `goop` key and are optional:

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| `prefix` | `string` | `'Goop'` | Prefix for the auto-imported components. `''` registers `Button`, `Slider`, and so on. |
| `css` | `boolean` | `true` | Add `@goopui/vue/goop.css` to `nuxt.options.css`. |
| `tailwindSource` | `boolean` | `true` | Add an `@source` for `@goopui/vue` to every Tailwind v4 entry CSS (any file that imports `tailwindcss`), so Tailwind generates the classes the components use. Turn it off if you import `goop.css` from your Tailwind entry yourself. |
| `preset` | `'subtle' \| 'playful' \| 'wild'` | `'playful'` | App-wide feel. See [Theming](/docs/getting-started/theming#presets). |
| `renderer` | `'svg' \| 'canvas'` | `'svg'` | App-wide renderer. |
| `finish` | `'solid' \| 'oil'` | `'solid'` | App-wide surface finish. |
| `splash` | `'near' \| 'escape' \| 'off'` | `'near'` | Where splash and shockwave particles go. |
| `reducedMotion` | `boolean \| 'auto'` | `'auto'` | `true` forces reduced motion on. `false` ignores the OS setting. |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@goopui/nuxt'],
  goop: { prefix: 'Goo', preset: 'subtle' },
})
```

`preset`, `renderer`, `finish`, `splash`, and `reducedMotion` are defaults. A prop on a component beats them. Not every component reads every default. `finish` and `splash` only matter to components built on the full drip engine, like Button. The smaller ones (Switch, Slider, Progress, ...) read `preset`, `renderer`, and `reducedMotion`, and the Toaster reads `preset` and `reducedMotion`.

### The Toaster

`GoopToaster` wraps [vue-sonner](https://vue-sonner.vercel.app). `@goopui/vue` installs it for you, but if you use the Toaster, add it to your app too (you call `toast()` from it) and include its stylesheet. See the [Toaster](/docs/components/toaster#installation) page.

```bash
pnpm add vue-sonner
```

## Vue

Install the package:

```bash
pnpm add @goopui/vue
```

Import the stylesheet after Tailwind. It holds the `--goop-*` tokens, the keyframes, and an `@source` so Tailwind picks up the classes the components use:

```css [main.css]
@import "tailwindcss";
@import "@goopui/vue/goop.css";
```

Then import components where you use them:

```vue [App.vue]
<script setup lang="ts">
import { GoopButton } from '@goopui/vue'
</script>

<template>
  <GoopButton>Gooey</GoopButton>
</template>
```

To set app-wide defaults, install the plugin. They take the same values as the Nuxt module options above:

```ts [main.ts]
import { createApp } from 'vue'
import { GoopPlugin } from '@goopui/vue'
import App from './App.vue'

createApp(App).use(GoopPlugin, { preset: 'subtle' }).mount('#app')
```

To set them for one part of the tree, call `provideGoopConfig({ preset: 'wild' })` in a parent component.

`@goopui/vue` depends on `reka-ui` and `@goopui/core`, so you don't install those yourself. `vue` and `tailwindcss` are peer dependencies. If you use the Toaster, add `vue-sonner` to your app as well, since your code imports `toast()` from it:

```bash
pnpm add vue-sonner
```

```css [main.css]
@import "vue-sonner/style.css";
```

## Next.js

Install the package:

```bash
pnpm add @goopui/react
```

Add one line to your Tailwind entry CSS, after Tailwind. It brings the `--goop-*` rules and keyframes, and an `@source` that points Tailwind at the package so it generates the classes the components use:

```css [app/globals.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

Use the components anywhere, Server Components included. Every component file is marked `'use client'`, so it server-renders shadcn's exact markup, and the goo attaches after hydration. There's nothing that can mismatch:

```tsx [app/page.tsx]
import { GoopButton } from '@goopui/react'

export default function Page() {
  return <GoopButton>Gooey</GoopButton>
}
```

App-wide defaults are optional. Wrap your app in `GoopProvider` in the root layout:

```tsx [app/layout.tsx]
import { GoopProvider } from '@goopui/react'
import './globals.css'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <GoopProvider preset="playful">{children}</GoopProvider>
      </body>
    </html>
  )
}
```

## Vite

Install the package, and Tailwind if you haven't yet:

```bash
pnpm add @goopui/react
pnpm add -D tailwindcss @tailwindcss/vite
```

```ts [vite.config.ts]
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

```css [src/index.css]
@import "tailwindcss";
@import "@goopui/react/goop.css";
```

```tsx [src/main.tsx]
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { GoopProvider } from '@goopui/react'
import App from './App'
import './index.css'

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <GoopProvider preset="playful">
      <App />
    </GoopProvider>
  </StrictMode>,
)
```

## Defaults

`GoopProvider` takes app-wide defaults. All of them are optional, and a prop on a component beats them. Providers can nest; an inner one overrides the outer one for its part of the tree.

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `preset` | `'subtle' \| 'playful' \| 'wild'` | `'playful'` | App-wide feel. See [Theming](/docs/getting-started/theming#presets). |
| `renderer` | `'svg' \| 'canvas'` | `'svg'` | App-wide renderer. |
| `finish` | `'solid' \| 'oil'` | `'solid'` | App-wide surface finish. |
| `splash` | `'near' \| 'escape' \| 'off'` | `'near'` | Where splash and shockwave particles go. |
| `reducedMotion` | `boolean \| 'auto'` | `'auto'` | `true` forces reduced motion on. `false` ignores the OS setting. |
| `sound` | `boolean` | `false` | Interaction sounds for every component. See [Sound](/docs/getting-started/sound). |

Not every component reads every default. `finish` and `splash` only matter to components built on the full drip engine, like Button. The smaller ones (Switch, Checkbox, Tabs, ...) read `preset`, `renderer`, and `reducedMotion`.

`@goopui/react` depends on `radix-ui`, `@goopui/core`, and `cuelume` (the sounds, loaded only when a component has `sound` on), so you don't install those yourself. `react`, `react-dom`, and `tailwindcss` are peer dependencies.
::

## Versions

::fw
#vue
All `@goopui/*` packages are released together with the same version number. `@goopui/nuxt` and `@goopui/vue` pin the exact versions of the packages under them, so updating the one you installed keeps everything in step:

```bash
pnpm add @goopui/nuxt@latest
```

With Vue (no Nuxt), update `@goopui/vue@latest` instead.

#react
`@goopui/react` and `@goopui/core` are released together with the same version number, and `@goopui/react` pins the exact core version, so updating it keeps both in step:

```bash
pnpm add @goopui/react@latest
```
::

## Components

::fw
#vue
Components are named with the `Goop` prefix and keep the shadcn-vue API. The full list is on the [introduction](/docs/getting-started/introduction#components) page. Each component has its own page with a live demo and its props.

#react
Components are named with the `Goop` prefix and keep the shadcn/ui API: the same parts, cva variants, `className`, and `asChild`. `ref` is the DOM element, as in shadcn; `goopRef` gets the goo engine (`drip()`, `press()`, ...). The React port so far has [Button](/docs/components/button), [Switch](/docs/components/switch), [Checkbox](/docs/components/checkbox), [Tabs](/docs/components/tabs), and [Dialog](/docs/components/dialog). The other pages show the Vue component and are marked *Vue only* until their React version lands.

`@goopui/react` isn't on npm yet. It will be published once a few more components are ported.
::
