`@goopui/core` is plain TypeScript and DOM. It has no framework and no dependencies, and it never touches `document` or `window` at import time, so it's safe to import during SSR. The Vue, React, and Svelte packages are thin wrappers around it. You only need it directly to put goo on something that isn't a goopUI component, or to build an adapter.

::callout{type="soon"}
The package is built and runs every demo on this site, but it isn't on npm yet (version `0.0.0`). The API below is what the source exports today.
::

## attachGoop

```ts
function attachGoop(host: HTMLElement, options?: GoopOptions): GoopHandle
```

This turns `host` into a goo body. It adds an `aria-hidden` goo layer inside the host at `z-index: -1` and sets `isolation: isolate` on the host (plus `position: relative` if it was `static`). Your content paints above the goo, unfiltered. Give the host a transparent background and set `--goop-color`:

```ts
import { attachGoop } from '@goopui/core'

const button = document.querySelector<HTMLButtonElement>('.save')!
button.style.setProperty('--goop-color', 'var(--primary)')

const goop = attachGoop(button, { dripCount: 2 })

// later
goop.update() // re-read --goop-* variables
goop.destroy()
```

In Vue, attach on mount and destroy on unmount. This site's demos use a wrapper like this one:

```vue [GoopHost.vue]
<script setup lang="ts">
import { attachGoop, type GoopHandle, type GoopOptions } from '@goopui/core'
import { onMounted, onUnmounted, ref, watch } from 'vue'

const props = defineProps<{ options?: GoopOptions }>()
const el = ref<HTMLElement | null>(null)
let handle: GoopHandle | null = null

onMounted(() => {
  if (el.value) handle = attachGoop(el.value, { ...props.options })
})
watch(() => props.options, (o) => handle?.update({ ...o }), { deep: true })
onUnmounted(() => handle?.destroy())
</script>

<template>
  <button ref="el" class="goop-button"><slot /></button>
</template>
```

## GoopOptions

`GoopOptions` takes every [tuning knob](#tuning) as an optional number (`blur`, `dripCount`, `viscosity`, and so on), plus:

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `drips` | `boolean` | `true` | Spawn drips on hover or tap. `false` gives a static goo body that still squishes. |
| `interactive` | `boolean` | `true` | Listen to pointer events on the host. Set it to `false` to drive the goo yourself with the handle's `press`, `release`, `hover`, and `drip`. |
| `disabled` | `boolean` | `false` | Ignore interaction. Drips already running finish, and nothing new starts. |
| `reducedMotion` | `boolean \| 'auto'` | `'auto'` | `'auto'` follows `prefers-reduced-motion` and `<html data-reduced-motion="true">`. `true` or `false` forces it. |
| `renderer` | `GoopRendererFactory` | SVG filter | Swap the renderer. See [Renderer](#renderer). |
| `random` | `() => number` | `Math.random` | RNG for drip placement and jitter. Pass a seeded one for tests. |

Tuning precedence: a JS option, then the `--goop-*` variable on the host, then the default. Values are clamped to `GOOP_LIMITS`.

## GoopHandle

| Member | Description |
| --- | --- |
| `update(opts?)` | Merge new options and re-read the `--goop-*` variables from the host. |
| `destroy()` | Remove listeners, observers, the rAF ticker, the DOM, and the filter reference. Restores the host's inline `position` and `isolation`. Safe to call twice. |
| `press()` | Squish the body, like `pointerdown`. |
| `release()` | Release the squish with a spring rebound, like `pointerup`. |
| `hover(on, x?)` | `true` starts hover drips (optionally near `x`, in host px). `false` pulls back drips that haven't detached. |
| `drip(x?)` | Spawn one drip that swells and detaches on its own, like a tap. |
| `layer` | The `aria-hidden` goo layer element (read-only). |
| `reducedMotion` | Whether the instance is currently in still mode (read-only). |
| `tuning` | The resolved tuning in use (read-only). |

Driving a goo body by hand, for example a dripping edge that follows the pointer from somewhere else on the page:

```ts
const edge = attachGoop(el, { interactive: false, squish: 0, restingDrips: 4 })

section.addEventListener('pointermove', (e) => {
  const x = e.clientX - el.getBoundingClientRect().left
  edge.drip(x)
})
```

## Tuning

These are the per-element knobs. Each one maps to a `--goop-*` variable:

:goop-vars-table

| Export | Description |
| --- | --- |
| `GOOP_DEFAULTS` | Default value for each knob (frozen). |
| `GOOP_CSS_VARS` | The CSS variable name for each knob, such as `blur` → `--goop-blur`. |
| `GOOP_LIMITS` | The `[min, max]` clamp for each knob. |
| `GOOP_PHYSICS` | Engine-level feel constants like spring responses, swell and drain times, and drop drag. They aren't exposed as CSS variables. |
| `readTuning(el, overrides?)` | Resolve the tuning for an element: defaults, then CSS variables, then overrides, all clamped. |
| `GoopTuning`, `SpringFeel` | Types. A `SpringFeel` is `{ response, dampingRatio }`, the way Apple-style springs are tuned. |

## Reduced motion

| Export | Description |
| --- | --- |
| `isReducedMotion(doc)` | One-time check: OS setting or `<html data-reduced-motion="true">`. |
| `watchReducedMotion(doc, cb)` | Subscribe to changes. The callback only fires on a change. Returns an unsubscribe function, and the listeners are torn down when the last subscriber leaves. |

## Animation loop

Every instance shares one `requestAnimationFrame` loop. It stops when nothing is moving, and a single frame step is capped (`GOOP_PHYSICS.maxDt`), so switching tabs doesn't make things jump.

| Export | Description |
| --- | --- |
| `setGoopTimeScale(scale)` | Slow the whole simulation down. `0.25` is quarter speed, handy for judging motion. The *Slow-mo* buttons on this site use it. |
| `isLoopRunning()` / `activeTickerCount()` | For tests and devtools. |
| `wakeTicker(t)` / `removeTicker(t)` | Low level: add or remove a `Ticker` (`(dt) => boolean`, which returns `true` while it's still moving). |

## Filter

There's one hidden `<svg>` per document. It holds a `<filter>` for each distinct parameter set, and each filter is ref-counted, so it's removed when its last user goes away. The pipeline blurs the source, crushes the alpha into a hard edge, and draws the original pixels on top so colors come from the source.

| Export | Description |
| --- | --- |
| `acquireGooFilter(doc, params)` | Get or create the filter for `{ blur, contrast, threshold }` and take a reference. Returns `{ id, release() }`. |
| `gooFilterMarkup(params, id?)` | The filter's markup as a string, for SSR or snapshot tests. |
| `gooFilterId(params)` | A deterministic, CSS-safe id. The same params always give the same id. |
| `gooColorMatrix(params)` | The `feColorMatrix` values string. |
| `gooFilterRefCount(doc, id)` | For tests. |
| `GOO_FILTER_REGION`, `GOO_DEFS_ATTR` | The filter region and the attribute on the shared `<svg>`. |

## Renderer

The simulation only talks to a `GoopRenderer`. The default one, `createSvgFilterRenderer`, draws plain `<span>`s (valid inside a `<button>`) in a filtered layer and changes only `transform` and `opacity` each frame. A canvas metaball renderer could implement the same interface later.

```ts
interface GoopRenderer {
  readonly layer: HTMLElement
  setParams(params: GooFilterParams): void
  setPadding(padding: { side: number; bottom: number }): void
  setBodyScale(sx: number, sy: number): void
  createBlob(): GoopBlob // set(x, y, r, opacity?, sx?, sy?) / remove()
  flush(): void
  destroy(): void
}
```

Parts carry a `data-goop` attribute (`layer`, `body`, `drips`, `blob`; the attribute name is `GOOP_PART_ATTR`) so tests and devtools can find them.

## Low-level physics

These are exported for adapters and tests. Most apps never need them.

| Export | Description |
| --- | --- |
| `DripField` | The drip simulation: spawning, swelling, necking, detaching, falling, and resting drips. |
| `springConfig(feel, viscosity?)` | Turn `{ response, dampingRatio }` into stiffness and damping. Viscosity slows the response and adds damping. |
| `stepSpring(state, target, cfg, dt)` | Closed-form damped spring step. Frame-rate independent. |
| `stepFall(state, gravity, drag, dt)` | Closed-form fall with linear drag. |
| `isSpringSettled(state, target, eps?, vEps?)`, `clampDt(dt, maxDt?)` | Helpers. |
