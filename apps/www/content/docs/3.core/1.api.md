`@goopui/core` is plain TypeScript and DOM. It has no framework and no dependencies, and it never touches `document` or `window` at import time, so it's safe to import during SSR. The Vue, React, and Svelte packages are thin wrappers around it. You only need it directly to put goo on something that isn't a goopUI component, or to build an adapter.

::callout{type="soon"}
The package is built and runs every demo on this site, but it isn't on npm yet (version `0.0.0`). The API below is what the source exports today.
::

## attachGoop

```ts
function attachGoop(host: HTMLElement, options?: GoopOptions): GoopHandle
```

This turns `host` into a goo body. It adds an `aria-hidden` goo layer inside the host at `z-index: -1` and sets `isolation: isolate` on the host (plus `position: relative` if it was `static`). Your content paints above the goo, unfiltered. Give the host a transparent background and set `--goop-color`:

```ts
import { attachGoop } from '@goopui/core'

const button = document.querySelector<HTMLButtonElement>('.save')!
button.style.setProperty('--goop-color', 'var(--primary)')

const goop = attachGoop(button, { dripCount: 2, splash: 'escape' })

// later
goop.update() // re-read --goop-* variables
goop.destroy()
```

Out of the box an attached element:

- drips on hover, more and faster the harder the pointer comes in;
- leans, wobbles, and carries momentum as the pointer moves (`inertia`), and its hanging drips creep toward the cursor (`flow`);
- swells a lump or two toward an approaching pointer before it even touches (`reach`);
- fires a click-like shockwave, aimed along the motion, when the pointer hits it fast: a hard entry or a fast swipe across or out (`hitEffect`, `splashMinSpeed`);
- squishes on press, and on release adds goo (`clickGoop`) and fires a shockwave from the click point (`shockwave`);
- pulls a stretchy taffy string when you press and drag off it (`taffy`);
- does the same press from the keyboard: Space or Enter squishes from the top (`keyboard`);
- sloshes when the page scrolls (`scrollSlosh`), and its resting drips breathe slowly (`idle`).

`preset: 'subtle' | 'playful' | 'wild'` sets the starting point for all of it. See [Theming](/docs/getting-started/theming#presets).

Old option and variable names (`blur`, `viscosity`, `--goop-threshold`, ...) still work as deprecated aliases. See [renamed variables](/docs/getting-started/theming#renamed-variables).

In Vue, attach on mount and destroy on unmount. This site's demos use a wrapper like this one:

```vue [GoopHost.vue]
<script setup lang="ts">
import { attachGoop, type GoopHandle, type GoopOptions } from '@goopui/core'
import { onMounted, onUnmounted, ref, watch } from 'vue'

const props = defineProps<{ options?: GoopOptions }>()
const el = ref<HTMLElement | null>(null)
let handle: GoopHandle | null = null

onMounted(() => {
  if (el.value) handle = attachGoop(el.value, { ...props.options })
})
watch(() => props.options, (o) => handle?.update({ ...o }), { deep: true })
onUnmounted(() => handle?.destroy())
</script>

<template>
  <button ref="el" class="goop-button"><slot /></button>
</template>
```

## GoopOptions

`GoopOptions` takes every [tuning knob](#tuning) as an optional number (`softness`, `dripCount`, `inertia`, `shockwave`, and so on), plus:

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `preset` | `'subtle' \| 'playful' \| 'wild'` | `'playful'` | Defaults for every feature. Also `--goop-preset`. Explicit options and variables still win. |
| `restingDrips` | `number \| (number \| { x, size?, length?, pinch?, phase? })[]` | `0` | Still drips on the bottom edge. A count spaces them evenly; an array places them at 0 to 1 fractions of the width. Objects also set each drip's size and length as multipliers, for an uneven, organic edge. `--goop-drip-variance` adds natural variety. |
| `hitEffect` | `'shockwave' \| 'splash' \| 'both' \| 'none'` | `'shockwave'` | What a fast pointer hit does. Also `--goop-hit-effect`. |
| `gloss` | `boolean \| number` | `false` | Wet look: a soft highlight and rim shading. `true` uses 0.6. |
| `taffy` | `boolean \| number` | `true` | Press and drag off to pull a stretchy string. Tune with `taffyLength`, `taffyStrands`, `globbiness`. |
| `reach` | `boolean \| number` | `true` | Lumps swell toward a pointer closer than this many px. Tune with `reachSize`, `reachGlobs`. |
| `puddles` | `boolean` | `false` | Falling drops land, spread flat, and drain (`puddleLife`). |
| `labelRide` | `boolean \| number` | `true` | Content marked `[data-goop-label]` moves and squishes with the goo (transform only, so text stays crisp). |
| `idle` | `boolean` | `true` | Resting drips breathe with a very slow swell. |
| `seed` | `number` | from the element | Seed for the resting-drip layout, so SSR and re-renders agree. |
| `splash` | `'near' \| 'escape' \| 'off'` | `'near'` | Where splash and shockwave particles go. `escape` flies them across the page in a shared overlay. Also `--goop-splash`. |
| `finish` | `'solid' \| 'oil'` | `'solid'` | Surface finish. `oil` is a thin-film iridescent sheen and picks the canvas renderer. Also `--goop-finish`. |
| `renderer` | `'svg' \| 'canvas' \| factory` | `'svg'` | How the goo is drawn. See [Renderers](#renderers). Can be switched with `update()`. |
| `escapeRenderer` | `'svg' \| 'canvas' \| factory` | `'canvas'` | Renderer for the shared page overlay that escape splashes fly in. |
| `timeScale` | `number` | `1` | Per-element speed. `0.3` is slow motion for just this element, multiplied with the global `setGoopTimeScale`. |
| `maxDrips` | `number` | `10` | Cap on live drips. Also `--goop-max-drips`. |
| `drips` | `boolean` | `true` | Spawn drips. `false` keeps the body, squish, splash, and shockwave. |
| `interactive` | `boolean` | `true` | Listen to pointer events on the host. Set it to `false` to drive the goo yourself with the [handle](#goophandle). |
| `keyboard` | `boolean` | `true` | Space and Enter on the focused host squish it from the top and add goo. |
| `disabled` | `boolean` | `false` | Ignore interaction. Drips already running finish, and nothing new starts. |
| `reducedMotion` | `boolean \| 'auto'` | `'auto'` | `'auto'` follows `prefers-reduced-motion` and `<html data-reduced-motion="true">`. `true` or `false` forces it. |
| `tilt` | `boolean` | `false` | Device tilt shifts gravity sideways on phones. Call `requestTiltPermission()` from a user gesture first on iOS. |
| `cssVars` | `boolean` | `false` | Write the body's pose to the host each frame as `--goop-x`, `--goop-y` (px), `--goop-skew` (deg), `--goop-sx`, and `--goop-sy`, so your content can ride along with the goo. |
| `random` | `() => number` | `Math.random` | RNG for drip placement and jitter. Pass a seeded one for tests. |

Tuning precedence: a JS option, then the `--goop-*` variable on the host, then the default. Values are clamped to `GOOP_LIMITS`.

## GoopHandle

| Member | Description |
| --- | --- |
| `update(opts?)` | Merge new options and re-read the `--goop-*` variables from the host. Changing `renderer` or `finish` swaps the renderer in place: live drips, particles, puddles, and taffy keep going. |
| `destroy()` | Remove listeners, observers, the rAF ticker, the DOM, and the filter or canvas. Restores the host's inline `position` and `isolation`. Safe to call twice. |
| `press()` / `release()` | Squish the body, then release it with a spring rebound, like a pointer press. |
| `hover(on, x?)` | `true` starts hover drips (optionally near `x`, in host px). `false` pulls back drips that haven't detached. |
| `drip(x?)` | Spawn one drip that swells and detaches on its own, like a tap. |
| `addGoop(amount?, x?)` | Add goo like a click does: swell the body and throw a drip at `x`. `amount` defaults to `--goop-click-goop`. |
| `shockwave(x?, y?, strength?, aim?)` | Fire a click shockwave at (x, y) in host px (default: the center): a particle ring and an edge ripple. `aim: { vx, vy }` (px/s) points it, for hosts that never see the pointer. |
| `feedPointer({ clientX, clientY })` | Drive the pointer from outside, for `interactive: false` hosts. While `hover(true)` is on it steers lean, inertia, flow, and drip placement. |
| `splashThrough(x, y, vx, vy)` | Punch goo through as if the pointer entered at (x, y) moving at (vx, vy) px/s. Particles go where `splash` says. |
| `inspect()` | What's driving the goo right now: pointer velocity, added mass, live drips and particles, slosh, scroll, splash mode. |
| `layer` | The `aria-hidden` goo layer element (read-only). |
| `reducedMotion` | Whether the instance is currently in still mode (read-only). |
| `tuning` | The resolved tuning in use (read-only). |

Driving a goo body by hand, for an element that can't take pointer events itself (a decorative strip, a layer under other content):

```ts
const edge = attachGoop(strip, {
  interactive: false,
  restingDrips: [{ x: 0.25, size: 1.2, length: 1.4 }, { x: 0.7, size: 1.5, length: 2 }],
  splash: 'escape',
})

area.addEventListener('pointerenter', () => edge.hover(true))
area.addEventListener('pointerleave', () => edge.hover(false))
area.addEventListener('pointermove', (e) => edge.feedPointer(e))
area.addEventListener('click', (e) => {
  const r = strip.getBoundingClientRect()
  // Aim the ring along the pointer's last motion.
  edge.shockwave(e.clientX - r.left, r.height / 2, 1.5, { vx: 1200, vy: 300 })
})
```

The hero on the home page doesn't need any of this: the whole panel is one interactive goo body on the canvas renderer.

## Tuning

These are the per-element knobs. Each one maps to a `--goop-*` variable:

:goop-vars-table

| Export | Description |
| --- | --- |
| `GOOP_VAR_META` | One entry per variable, keyed by option: name, option, label, description, unit, default, range and step, group, cost, reduced-motion behavior, and old aliases. The docs table and the tuner on this site are built from it. |
| `GOOP_PRESETS`, `GOOP_PRESET_VAR`, `GOOP_DEFAULT_PRESET`, `readPreset` | The presets and how they resolve. |
| `GOOP_VAR_RENAMES`, `GOOP_OPTION_RENAMES`, `renameOptions` | Old variable and option names mapped to the new ones. |
| `GOOP_DEFAULTS` | Default value for each knob (frozen). |
| `GOOP_CSS_VARS` | The CSS variable name for each knob, such as `softness` → `--goop-softness`. |
| `GOOP_LIMITS` | The `[min, max]` clamp for each knob. |
| `GOOP_SPLASH_VAR`, `GOOP_DEFAULT_SPLASH` | `--goop-splash` and its default, `'near'`. |
| `GOOP_FINISH_VARS`, `GOOP_FINISH_DEFAULTS`, `readFinish(el, overrides?)` | The oil finish variables, their defaults, and the resolver. |
| `GOOP_PHYSICS` | Engine-level feel constants like spring responses, swell and drain times, and drop drag. They aren't exposed as CSS variables. |
| `readTuning(el, overrides?)` | Resolve the tuning for an element: defaults, then CSS variables, then overrides, all clamped. |
| `GoopTuning`, `GoopVarMeta`, `GoopPreset`, `GoopSplashMode`, `GoopFinishName`, `SpringFeel` | Types. A `SpringFeel` is `{ response, dampingRatio }`, the way Apple-style springs are tuned. |

## Renderers

Two renderers draw the same simulation, so a knob means the same thing in both:

```ts
attachGoop(el)                          // 'svg' (default): SVG goo filter on DOM spans
attachGoop(el, { renderer: 'canvas' })  // WebGL2 metaballs, Canvas 2D fallback
attachGoop(el, { renderer: makeCanvasRenderer({ backend: '2d' }) })
attachGoop(el, { finish: 'oil' })       // picks 'canvas' for you
```

- **SVG** draws plain `<span>`s (valid inside a `<button>`) in a filtered layer and only changes `transform` and `opacity` each frame.
- **Canvas** gives each element its own small `<canvas>` in the same layer, so scrolling, clipping, and stacking don't change. One shared WebGL2 context per document draws every element in a single batch. Without WebGL2, or after a context loss, it falls back to Canvas 2D with the same filter and switches back when the context returns. It reads `--goop-color` from computed style and repaints on theme and class changes; call `update()` after any other color change made while the goo is idle.

Escape splashes fly in one shared, fixed, full-viewport overlay (`acquireGoopOverlay`). You can use it too, for goo that has to leave its component.

| Export | Description |
| --- | --- |
| `createSvgFilterRenderer`, `createCanvasRenderer`, `makeCanvasRenderer(opts)` | The built-in renderer factories. |
| `resolveRenderer(option)` | Turn `'svg' \| 'canvas' \| factory` into a factory. |
| `acquireGoopOverlay(doc, opts)`, `acquireEscapeLayer`, `goopOverlayCount()` | The shared page overlay. |
| `gooCanvasBackend()`, `gooCanvasRefCount()` | Which canvas backend is live, for tests and devtools. |
| `GoopRenderer`, `GoopFinishRenderer` | The interfaces a custom renderer implements. Parts carry a `data-goop` attribute (`GOOP_PART_ATTR`) so tests and devtools can find them. |

## Reduced motion

Under reduced motion every element switches to a still mode, whatever the preset. The body shape and resting drips stay (without breathing). The drip simulation, wobble, momentum, flow, reach, taffy, label ride, scroll slosh, splashes, shockwaves, and puddles stop, and the oil sheen holds still. Each variable's own behavior is in its `reducedMotion` note in `GOOP_VAR_META`. The engine watches the setting live, so turning it on mid-session clears anything in flight.

| Export | Description |
| --- | --- |
| `isReducedMotion(doc)` | One-time check: OS setting or `<html data-reduced-motion="true">`. |
| `watchReducedMotion(doc, cb)` | Subscribe to changes. The callback only fires on a change. Returns an unsubscribe function. |

## Animation loop and input

Every instance shares one `requestAnimationFrame` loop. It stops when nothing is moving, and a single frame step is capped, so switching tabs doesn't make things jump.

| Export | Description |
| --- | --- |
| `setGoopTimeScale(scale)` | Slow every goo on the page down. For one element, use the `timeScale` option instead. |
| `isLoopRunning()`, `activeTickerCount()`, `loopStats()` | For tests and devtools. |
| `wakeTicker(t)` / `removeTicker(t)` | Low level: add or remove a `Ticker` (`(dt) => boolean`, which returns `true` while it's still moving). |
| `trackPointer`, `trackScroll`, `trackTilt`, `requestTiltPermission()` | The shared input trackers behind momentum, scroll slosh, and tilt. |

## Filter

The SVG renderer keeps one hidden `<svg>` per document, holding a `<filter>` for each distinct parameter set. Each filter is ref-counted and removed when its last user goes away. The pipeline blurs the source, crushes the alpha into a hard edge, and draws the original pixels on top so colors come from the source.

| Export | Description |
| --- | --- |
| `acquireGooFilter(doc, params)` | Get or create the filter for `{ blur, contrast, threshold }` and take a reference. Returns `{ id, release() }`. |
| `gooFilterMarkup(params, id?)` | The filter's markup as a string, for SSR or snapshot tests. |
| `gooFilterId(params)`, `gooColorMatrix(params)`, `gooVanishRadius` | Helpers. |
| `createOilFilter`, `OIL_PALETTE` | The oil finish's 2D-fallback filter and palette. |

## Low-level physics

These are exported for adapters and tests. Most apps never need them.

| Export | Description |
| --- | --- |
| `DripField` | The drip simulation: spawning, swelling, necking, detaching, falling, and resting drips. |
| `ParticleFluid`, `fluidParams`, `drainRadius`, `liveParticleCount` | The particle fluid behind splashes and shockwaves. |
| `springConfig(feel, viscosity?)` | Turn `{ response, dampingRatio }` into stiffness and damping. |
| `stepSpring`, `stepFall`, `isSpringSettled`, `clampDt` | Closed-form spring and fall steps. Frame-rate independent. |
